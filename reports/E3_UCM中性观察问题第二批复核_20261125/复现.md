# 第二批复核与合并重算

第二批与首批共用保留的两份 R2、读取器、27 个问题、真实工具以及随机数。训练集原始 84 对图按属性分别排序。每种属性的第一对进入首批，第二对进入复核批。在本机保留这两份同级报告以及原训练面板报告。`code/lock.py` 会检查两批的图像名、解码像素摘要、图对无交集。每批 54 图，两批共有 108 张不同照片、54 个自然图对。每种属性都用其余标签不变的同一句英语观察问题。

服务器目录 `/private/AGSE_E3_1_rebuild_20261112/attribute_questions_repeat_20261125`。原始轨迹和向量按权重在 `records/a`、`records/b`；机器和权重摘要在 `records/runtime.json`。服务器从本目录依次运行 `bash code/queue.sh`、`bash code/check_queue.sh`，重放两种子两种输入各自首批的 8 个动作和部署贪心终止向量，并核查第一对图两种权重两种输入的全部 136 个检索读出。

取回完整记录后，在本机本报告目录执行：

```bash
export OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python3 code/analyze.py
python3 code/selection_diagnosis.py
python3 code/pooled.py
python3 code/floor_check.py
shasum -a 256 -c records/logs.sha256
```

`results/summary.json` 仅含本批，`results/pooled.json` 使用两批全部逐图记录，按 27 种属性整体配对重采样 20,000 次。两批同属性的两对图片、两种提示和两个种子随同一抽样单位进入区间。判别“同时改善”的参照始终是本图本权重以原场景提示生成一次；普通 RR 对训练阶段留出的普通配文和负描述计分，完整测试图库上的 mR 另由正式单次生成实验评价。
