# 追加的措辞迁移检查

查看已锁定 A、B 的整组汇总后，追加一次探索性文本检验，沿用 16 对原图和已生成的所有向量。新增措辞 C 由未接触候选分数的视觉复核者按原图及既有命题独立编写，C 在本次比较中只作评量。主要比较同图 8 个候选中，分别按原代理奖励、A 分差、B 分差、A 和 B 的平均秩选择后在 C 上的判对率与相似度分差。平均秩在同一张图的 8 条候选中计算，A 和 B 各占一半，以减少原始分差尺度的影响。选择器并列时平均其结果。以等概率随机选作参照，按原自然图对做 20,000 次聚类重采样。两种查询单列。另记录 8 个候选中是否存在同时判对 A、B、C 的候选。C 复用同一批图和视觉标签，结论只描述措辞迁移。本检查不根据 C 的得分再选配方。
