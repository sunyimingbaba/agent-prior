# 实验复现

A100 工作目录为 `/private/AGSE_E3_1_rebuild_20261112/relation_transfer_20261120`。使用 `/private/AGSE_E1_20261110/legacy/env/bin/python`，设置 `PYTHONUTF8=1`、`LC_ALL=C.UTF-8`。在新的工作副本建立 `scratch/`，保留随包交付的冻结输入与视觉复核记录。训练和验证的模型、Arrow 和代理图像库路径见 `train/binding.json`、`val/binding.json`。判别器权重固定，生成与读出均可分开复算。

1. 样本清单从 `code/screen.py`、`code/design.py` 生成，输入参数为原版 UCM Arrow 目录。训练、验证照片分开读取，原生查询、源行号和 RGB 哈希一一对应。`code/seal.py` 依据评分前像素复核冻结主分析清单。补充双物体样本由 `code/object_cases.py <Arrow目录>` 列出。审核前排版图和审核意见均已保存。重建画面重叠筛查可运行 `code/overlap.py <Arrow目录>`，双物体组再传入 `object_inputs/cases.json object_inputs`。
2. 运行 `python code/generate.py` 后依次运行 `bash code/run_stage.sh`、`bash code/run_holdout.sh`。代码采用同一冻结 LoRA，按图、输入条件和种子生成随机及贪心轨迹。`train/decision.json` 保存短训条件逐项判断。复算请在独立工作副本执行，保留原始日志与冻结清单。
3. 双物体补充按 `python code/object_generate.py`、`python code/object_readout.py` 顺序执行。每张照片的像素旋转 180°，重走 Agent 工具循环，交换正确与错误的方向语句。`object_inputs/lock.json` 绑定标注、裁决与补充方案。
4. 仅做数值复核可以使用 CPU 的 PyTorch、NumPy 和 SciPy。分别给 `code/analyze_split.py`、`code/consistency.py`、`code/native_reward.py` 传入 `train` 或 `val`。运行 `code/sensitivity.py` 和 `code/verify.py` 核对高置信子集、逐候选分数和归档比对。评分表中标为原奖励的值按格式分加目标图名次倒数计算；验证代理图库 210 项，训练代理图库 1680 项。
5. `code/full_val.py` 读取原始验证先验，对 210 图和全部 1050 条带归属的原描述计算六项召回的均值。场景输入替换仅涉及已锁定的 16 行。精确相同得分在名次边界均匀处理。多候选并列选择和随机选择使用 64 次共同随机抽样估计整库结果。`code/rotation_swap.py` 对同一图的像素与先验交叉输入，拆分两者对旋转响应的贡献。

`code/paired_choices.py` 复算两个视图独立抽取及共用随机数两种并列处理方式。`code/verify_object.py` 从保存的原生向量核对双物体组 198 条轨迹和 792 个方向分差。`python code/manifest.py --verify` 核对交付文件的字节数与 SHA-256。

整库召回的交付值在完成 `full_val.py` 后运行 `python code/full_val_stable.py` 得到。该步骤固定浮点累加顺序，先计算唯一 token 的相似度再展开描述归属。首轮整库结果按原文件保留。
