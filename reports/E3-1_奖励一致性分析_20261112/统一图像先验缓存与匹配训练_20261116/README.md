# 统一图像先验缓存与匹配训练

本阶段固定均衡第32步Agent、统一图像查询和原生EOS协议，补齐1680张train与210张test的1890份先验，复用210张val状态，共2100份。随后以同一现有AGSE初始化、同一7999样本顺序和原始三项损失，依次运行原生、校准自身、校准共享、仅可学习视觉提示四组10轮适配训练，每组320次更新。

活动训练方案为 `training_plan_v2.json`；CPU预检实现v3通过，正式训练入口 `code/train_arm_v4.py`，运行前按各哈希清单核对。预检v1核实了按图去重后的7999样本数，v2核实了偏置的单例批维，修订前源码、日志和方案完整保留；正式读出优化在修订完成后启动。

四组均按val210未舍入mR选检查点，平局取最早轮。锁定四组检查点后统一执行test210；另在同一检查点上用共享先验替换自身先验作对照。主指标沿用仓库重复token描述等价正例规则，并补充严格图像对应结果。数量85图沿用原始标签，其中63张train归入训练诊断，22张val单列。

仅可学习视觉提示组将视觉门控固定为1，并在原始先验KL项中保留校准共享常量，以保持训练损失结构一致。四组均冻结CLIP，固定当前LoRA并使用离线先验。

本文件记录执行前方案；实际进度、结果和双端核验由运行日志及后续阶段报告给出。
