# 协议提示修复与候选状态验证

阅读入口为 `协议提示修复与候选状态验证结论_20261116.md`。`analysis.json` 和 `retrieval_summary.csv` 保留全部270组对照、三种检索协议与预先声明的238组配对区间；`protocol_witnesses.json` 按每类停止原因保留确定性代表轨迹。

`protocol_plan.json` 封存训练63图选择提示的规则、210图验证及六类状态定义。`protocol_execution_addendum_v2.json` 记录初始试运行后新增保护措施的原因；V1的14条已完成轨迹、源码和日志全部保存。V2提示选择只使用train63的协议结果，实际状态逐步矩阵存于完整归档中。

`原始运行记录/` 是本机归档恢复目录。服务器对应目录为 `/private/AGSE_E3_1_rebuild_20261112/protocol_prompt_state_validation_20261116`。完整XZ归档与其SHA、文件清单在 `备份校验.json`、`服务器最终备份核验.json` 中记录。Git中的 `归档分卷/` 可按 `code/evidence_parts.py` 校验并重组；父阶段模型检查点继续使用 `inputs/parent_dual_backup_reference.json` 引用的双端归档。

本机复核命令使用已有Python环境，依赖torch、numpy、tokenizers；制图另需matplotlib。以`原始运行记录`作为`--root`，以前一阶段对应的原始恢复目录作为`--parent`和`--matched`：

```sh
python code/verify_generation.py --root 原始运行记录 --matched 上一匹配训练的原始目录 --out 重新核验生成.json
python code/verify_evaluation.py --root 原始运行记录 --parent 上一图像依赖诊断的原始目录 --matched 上一匹配训练的原始目录 --out 重新核验评估.json
python code/verify_descriptive.py --root 原始运行记录 --out 重新核验描述统计.json
python code/verify_cohort_binding.py --root 原始运行记录 --parent 上一图像依赖诊断的原始目录 --out 重新核验图像身份.json
```

上述四项核验分别重建实际token与状态位置、全部检索和数量指标及区间、状态统计、逐行图像身份和封存提示。`EXPERIMENT_AUDIT.json` 与 `.aris/traces/experiment-audit/` 保留独立审阅原文及输入哈希，审阅关系标注same-family/provisional。

本阶段采用真实检索标注与既有人核数量标签；格式、状态离散度及门控用于描述性诊断。生成描述的语义正确性为[待确认]。现有val继续用于固定模型开发诊断，下一节点详见 `下一阶段匹配读出与语义验证_20261116.json`。
