# E3 奖励跨图复验与单次生成核对

**真实图文奖励已经能更好地从同图候选中挑出有助于普通文字检索的先验。** 在四组共 57 张 UCM 验证图上，按原 RFPO 选择时，其他真描述的平均倒数排名（MRR）为 0.509，改按真实图文分选择后为 0.646，差值 +0.137，图对或源图配对 95% 区间 [+0.041, +0.234]。按 17 个 UCM 场景类别整组重采样，区间为 [+0.045, +0.232]。方向困难负样本的额外收益和一次生成的策略提升仍待验证。

## 决策依据

每张图的候选都来自已部署的同一历史 Agent，生成时只给场景提示。真实图文奖励用该图第一条真实描述的分数减去一组负描述中的最高分。在比较各方法时，为兼容使用两条正描述的对照，统一移除前两条不同的正描述，余下标注的 token 组与奖励用过的正描述互斥。评价还使用另一半负描述。选择器能读取训练时可用的标注。部署时由 Agent 自行生成先验的表现另行核对。

| 验证照片与候选数 | 原 RFPO 选出的 MRR | 真实图文选出的 MRR | 普通匹配的含义 |
|---|---:|---:|---|
| 前三组 41 图，每图 8 条 | 0.534 | 0.659 | 在三组的同一批候选中配对比较 |
| 第四组 16 图，每图 4 条 | 0.448 | 0.614 | 配方固定后的额外留出图 |
| 合计 57 图 | 0.509 | 0.646 | 各图等权 |

第一行的原 RFPO 含补跑的 14 图原代理分，对应的逐候选目标排名已归档。额外 16 图中，MRR 提高 0.166，95% 区间 [−0.012, +0.353]；改用所有留出真描述的倒数排名平均值，增量为 +0.203，区间 [+0.039, +0.387]。合计 57 图用全部留出真描述的均值时，结果从 0.390 到 0.506，增量 +0.115，区间 [+0.042, +0.190]。四组均为已有历史研究记录的验证场景；图号与本轮开发样本互斥，正式测试划分留待最终实验。

## 检索器整库复验

保持 UCM 原验证图库 210 图、1,050 条描述，57 张改用各方法选中的先验，其他 153 张使用历史首句先验。所有方法均使用同一冻结检索器。在 57 张图上，原奖励和真实图文都从相同的场景提示候选中选一条。表中贪心行改用同一场景提示下的一次贪心输出。表中的 mR 均为双向六项召回的平均值。

| 57 张图上的先验取法 | 完整图库 mR | 排除评分所用文本后的 mR |
|---|---:|---:|
| 每图随机取一条 | 54.99% | 55.77% |
| 同场景提示下贪心生成一条 | 56.15% | 56.53% |
| 原 RFPO 选择 | 55.06% | 56.39% |
| 只用真实图文奖励选择 | **57.98%** | **57.87%** |
| 真实图文加固定 25% 方向奖励 | 57.89% | 57.82% |
| 真实图文接近时再用方向奖励选 | 57.90% | 57.90% |

真实图文相对原 RFPO 的完整图库增量为 +2.91 个百分点，固定图库、按来源图配对的 95% 区间为 [+1.14, +4.79]。完整图库含奖励打分用过的原描述。严格过滤时，排除全库首句、目标图参与打分的第二条正描述，以及进入奖励负例池的文本，余下 350 条描述对应 191 张查询图，文检图仍检索全部 210 图。真实图文比原 RFPO 高 1.48 点，区间为 [−0.74, +3.76]。整库估计包含并列候选均匀选取，使用 64 次共用抽样。全体 210 张均采用历史首句生成的原部署方案，重放 mR 为 60.06%。

## 困难负样本与跨措辞评分

开发集原有两组共 76 张训练图。1933.tif 仅有两个不同正描述 token 组，给评分分配两条后缺少留出正例，因此 75 张共同参与开发和选参数。在一条或两条正描述的真实图文分上，分别试 4 档非零容差，两个方案均在读验证候选前锁定为 0.001。只有靠近真实图文最高分的候选，才由正确方向句与反向句的分差决定赢家。固定 25% 方案作为上阶段对照。

| 方法 | 57 图方向判对率 | 57 图留出真描述 MRR |
|---|---:|---:|
| 原 RFPO | 51.75% | 0.509 |
| 随机 | 53.84% | 0.520 |
| 纯真实图文 | 53.51% | 0.646 |
| 加固定 25% 方向分 | 53.07% | 0.665 |
| 图文近分时按方向分改选 | 52.63% | 0.630 |
| 两条真实描述的平均分 | 53.51% | 0.668 |
| 两条真实描述近分时按方向分改选 | 52.63% | 0.666 |

方向题按图等权，先在每幅图内平均其留出措辞。首批和第四组的候选数、关系类型和验收措辞各有差异。25% 权重相对纯真实图文的方向增量为 −0.44 个百分点，95% 区间 [−4.39, +4.39]。近分再判方向的增量为 −0.88 点，区间 [−2.63, 0.00]。第四组 16 图上，单句真实图文、25% 困难负样本和近分规则的方向判对率均为 56.25%。本轮结果支持保留纯真实图文作为检索奖励的基线，未出现具有独立方向增益的困难负样本配方。

针对措辞敏感性，另用训练文本的向量差拟合方向评分器，按 UCM 场景类别整组留出，每张图都由其他场景训练出的评分器打分。纯真实图文在开发集为方向判对率 52.00%、MRR 0.446。方向表现最高的诊断配方达到 60.80%，MRR 降至 0.394。最接近筛选线的 25% 配方方向为 56.17%，MRR 为 0.424，下降 0.022，略超过事前设定的 0.02。该分支在开发阶段结束。

## Agent 单次生成是否改善

重新读取历史同起点、每组 24 个训练组的三个 LoRA 和起点的**实际贪心生成向量**，按统一检索器分数重新计算 210 张图的检索结果。下表对应每图输入自己的第一条描述。另将全库所有输入首句的 token 组剔除，保留 829 条描述，210 图都有剩余标注。

| 历史策略 | 完整图库单次生成 mR | 移除全库首句后的 mR |
|---|---:|---:|
| 追加训练前 | 60.06% | 60.11% |
| 原 RFPO 追加训练 | 49.06% | 49.71% |
| 真实图文追加训练 | 48.25% | 49.24% |
| 真实图文＋困难负样本追加训练 | 50.16% | 50.69% |

移除首句后，历史困难负样本组较真实图文组高 1.45 点，95% 区间 [+0.05, +2.96]，较原 RFPO 高 0.98 点，区间 [−2.46, +4.38]。三个续训模型均低于同一起点。历史新奖励组与原奖励组还存在格式项和分数尺度差异。本轮完成的是奖励选择、跨图验证和已训练策略的部署复验，未新训练 LoRA。现有证据支持真实图文奖励的候选选择价值；冷启动后能否将这一优势学到单次生成中，仍是下一项独立研究问题。

## 复核材料

本地使用冻结重建原代理，先逐条复算已知的 128 条候选，其目标排名 128/128 完全一致，再补齐其余验证组的代理分。普通检索的成对结果还按场景类别独立复算，并回放历史归档 mR。复现命令依次为 `python3 experiment.py develop`、`python3 experiment.py confirm`、`python3 proxy_replay.py`、`python3 direction_reader.py`、`python3 independent.py`、`python3 gallery_replay.py`、`python3 gallery_replay.py --extra`、`python3 policy_replay.py`、`python3 verify.py`。原始输入来自现有 E3 报告目录及本地冻结模型文件。各阶段的输入哈希、逐图分项、选中的候选编号和对照分数随结果保存。
