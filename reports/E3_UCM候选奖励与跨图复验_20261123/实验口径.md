# UCM 候选奖励的训练图开发和跨图复验

先在 32 张实体关系训练图及另 44 张方向训练图开发，仅用场景查询、原朝向、温度采样的 8 条候选。按图等权，训练组和验证组按文件名与数据归属去重。锁定选择器后一次应用到既有的 16 张方向、11 张实体、14 张新标注方向验证照片。三组只在本次训练图配方选择中留出，此前均有历史研究记录。检索器、Agent 及数据标注均固定。

1. 基线为随机选、历史原 RFPO（有归档时）、真实首句对最难负描述的分差、以及 75% 真实图文秩加 25% 单措辞 A 的秩。主实验先留住真实图文分离最高值不超过固定余弦分差的候选，再用 A 的正确句与反向句分差打破平局。容差尝试 0、0.001、0.003、0.006、0.01，不用验证图选容差。
2. 第二条路线考虑同图的多条合法描述。对前两个不同 token 序列的真实描述等权求平均，再减最难负描述的余弦分。测试同样的容差。两条路线均使用相同的留出其余正描述、同一组奇数哈希负描述和同一冻结读出。另报使用全部留出正例的平均排名倒数，检查最佳正例主指标的敏感性。多描述单项和首句单项是各自的基线。
3. 困难负样本只用已核对的 A 措辞评分。外层方向检查用 32 图的 B/C、44 图及 16/11 图的 C/D、14 图的 B。只评可用于同一比较的独立措辞。验证图真描述和 A 方向标签只用于模拟训练奖励。计算任何方法的普通检索验收时，一致剔除两条奖励正描述，排除正例 token 重复。评估不传入真值给 Agent。另做普通描述负池的半池交换敏感性分析。
4. 两种路线分别从可选非零容差中选一档。以 76 张训练图综合方向准确率为优先，要求相对该路线纯图文在训练图上普通 MRR 回落不超过 0.02（沿用早期 UCM 开发标准），若均超限则取容差 0。并列优先普通 MRR，再优先较小容差。保存选择和原始分项哈希后读取验证候选。同时固定多描述的纯图文基线，用于辨别普通匹配与困难负样本各自贡献。
5. 主报告用按图配对区间，16 张方向图按自然图对重采样，两个实体集按源图重采样，三个验证组分层、图等权、20,000 次。困难负样本收益须与同一组正例的纯图文基线比较。将方向改善的区间下限大于 0 且普通 MRR 变化区间下限高于 −0.02 作为晋级证据，作为两条路线的保守检查同时报告 97.5% 区间。其他观察按实际证据陈述。新奖励须在独立图上通过此关才进入正式策略训练。较易单独验证的普通匹配进展与方向收益分别报告。每个开发组、外部验证组的方向题定义不同，各自单列。
