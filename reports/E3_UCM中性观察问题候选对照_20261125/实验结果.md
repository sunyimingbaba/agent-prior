# E3 中性观察问题候选对照 · 第一批

在 54 张 UCM 训练图上冻结两份此前保留的 R2 和同一检索器，各做场景提示、场景加属性问题两种实验。每种输入在每图采 16 条完整轨迹，再单独贪心生成一次。共 3,456 条采样、216 条贪心轨迹，无模型参数更新。每种属性一个自然图对，两侧收到逐字相同的问题。所有效果均与同图原场景提示的一次贪心输出比较。[问题与图片清单](inputs/lock.json)

| 核对项 | 只给场景 | 加入观察问题 |
| --- | ---: | ---: |
| 种子 a，采到至少一个双项改进候选的图 | 7/54 | 10/54 |
| 种子 b，相同读数 | 7/54 | 9/54 |
| 有双项改进候选时，R2 挑中的概率 | 28.57% | 43.91% |
| 有双项改进候选时，多描述 R3 挑中的概率 | 28.57% | 55.58% |
| 全部图用多描述 R3 挑中双项改进候选的概率 | 3.70% | 9.78% |
| 每图仅贪心一次，留出细节正确率 | 61.57% | 60.19% |
| 每图仅贪心一次，留出普通描述 MRR | 0.4827 | 0.4417 |

双项改进指留出 B/C 两种措辞的细节正确率和留出普通描述的倒数名次都严格提高。两种子的有机会图占比从 12.96% 升至 17.59%，增加 4.63 个百分点，按自然图对配对重采样的 95% 区间为 [−0.93, +12.04]。在问题组的 19 次有机会的“图像、种子”组合中，R3 相对 R2 的选中概率多 11.67 个百分点，区间 [0.00, +36.82]。两项主检验都观察到正向趋势，区间下界均未高于零。全体图固定使用 R3 的选中概率增加 6.07 个百分点 [+0.59, +12.50]，属于候选筛选读数。贪心细节差 −1.39 个百分点 [−7.87, +5.09]，贪心普通 MRR 差 −0.0410 [−0.1120, +0.0234]。[主读数与两份种子](results/summary.json)

以海滩图 `380.tif` 为例，近岸浪花很少。只给场景时，两份权重各自采到 6/16 个双项改进候选，R2 和 R3 的最高分候选都错过了它们。加入与同对另一张图完全相同的“沿岸浪花带有多宽？”后，两份权重分别采到 9/16、7/16 个双项改进候选，两个奖励的最高分候选在两份权重上都达到了双项改进。另一方面，这张图在带问题时只生成一次，两个种子的细节得分都从 1/2 降到 0/2。这个例子区分了“16 选一”和“一次生成”的实际结果。[逐图数据](results/per_image.json)

由于原场景贪心在部分图上已经达到细节或普通排名满分，54 张图中严格双项改进有上升空间的分别只有 18、17 张。用“改善细节、普通名次至少持平”复核，出现候选的图数在种子 a 为 12→12、种子 b 为 13→14。事后追查问题组的 19 次机会，8 次所有双项改进候选都低于 R3 的普通描述优先门槛。[选中过程](results/selection_diagnosis.json)

首批保留原 R2，追加同一属性另一对照片的固定问题复核。独立评分代码重算了 136 个隐藏向量，代理名次完全一致，最大绝对误差为 4.5×10⁻¹⁶ 以内。原部署贪心向量及两份权重两种输入的首批采样动作复核吻合。所有照片均来自训练划分，属性由标注给出，两种子共用同一组照片。[评分核验](results/score_recheck.json) · [复现说明](复现.md)
