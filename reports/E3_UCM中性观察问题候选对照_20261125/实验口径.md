# 相同属性问题能否增加有助于检索的候选

固定当前保留的两份第二轮 R2 权重和同一冻结 CUP，不更新模型。用原 84 对训练图，按属性分层，每种属性取一个自然图对，以预定盐和图对 ID 的 SHA-256 选择。每对两边的场景与问题逐字相同，问题按属性拟定，只点出要观察的对象，无正确侧别、选择顺序、示例答案或数值。全部图对进入结果。原有同图细节说法 A 用于 R3，B/C 两种留出说法只用于计分。初次结果揭晓前封存问题和名单。

同一份权重在同一图上各运行两种输入，场景提示、场景提示加中性问题。每个输入从第一轮起自由采 16 条完整轨迹，两批各 8 条。温度 1，top-k 50，最多三轮，每轮 64 个词元。每次调用原场景工具时使用此前由该工具在同一图真实产生并存档的返回。保持原部署入口的回填格式、终止向量、检索器、评分文本和负描述库。对两种输入各自由贪心一次。配对随机数按种子、图、批、轮和轨迹组生成。工具分支不同时允许续写前缀不同。这里比较的是整条采样轨迹，不同于前一轮已经固定首轮的第二轮采样。

所有候选都与该图原场景提示的一次贪心结果比较。好候选须使留出 B/C 两个措辞的平均正确率以及普通留出正确描述的倒数名次都严格提高。主指标一为有至少一个好候选的图占比。主指标二为问题组存在好候选时，原多描述 R3 与 R2 选中好候选的概率差，各自的最高分并列时等概率选取。同报原场景输入的结果、全体图的选中率、每种子独立结果、可提升空间（基准满分的图数）及单次贪心读出。普通倒数名次的图库、描述和负例划分与上一阶段训练图复核一致。

先在图内配对，再按自然图对聚类，对两个固定种子共用相同重采样，20,000 次估计 95% 区间。有机会组的条件概率按实际图和种子出现次数加权。两项主指标的两份种子均为正且各自汇总区间下界高于零，视为有明确改善，进入短程 RFPO 并在无额外问题的新图上验收。其余情形保留原 R2，记录究竟是好候选稀少，还是奖励挑选效果不足。
