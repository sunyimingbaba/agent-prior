# 中性观察问题候选对照复现说明

计算目录为学校 5090 的私有挂载 `/private/AGSE_E3_1_rebuild_20261112/attribute_questions_20261125`。保留上一阶段及其相邻目录以沿用已核验的两份 R2、工具返回、冻结 CUP 和文本库。实际权重、源文件摘要和运行环境见 `records/runtime.json`。源图和原配描述仅使用训练划分。原始面板 A 的正负差用于打分，B/C 留出用于验收。普通 RR 是剩余原配描述中最高分相对另一批负描述的倒数名次，名次并列时平均可能的倒数名次。

`code/lock.py` 由问题表和训练面板生成清单。相同属性只用一个问题；选图完全按固定哈希，不读取候选得分。两边维持相同场景描述，在问题臂中在原文本末尾加入同一英语问句。每个图对两张、每种子各 2 种输入，每种输入 16 条随机轨迹和 1 条贪心轨迹。相同续写上下文可合批，最多 8 条；有工具调用时按生成的调用文字和该图的实际返回继续，最多三轮。原始逐轮词元、检索分数、终止隐藏态的摘要在 `records/a` 和 `records/b`。每图记录和最终完成清单按摘要复核。采用全轨迹采样，因此本轮的两种输入互为直接对照，和上一阶段的工具后采样另列。

服务器依次运行 `bash code/queue.sh` 和 `bash code/check_queue.sh`。后者用原有采样入口复核两种子、两种提示的首个随机批次，重放标准部署入口的贪心向量，对预先选定的第一对图用另一实现核验评分。取回两个种子记录后，在本机本报告目录执行以下命令。

```bash
export OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python3 code/analyze.py
shasum -a 256 -c records/logs.sha256
```

`results/summary.json` 中 available 的 change 为加问题后有好候选的图占比变化；conditional_question 的 increment 为有好候选时 R3 减去 R2 的选中概率。每个图和种子最高分并列时均分选中概率。若某种子没有任何机会，条件概率记为空值。不同指标的普通级别与差值均以原始比例存储，报告中换算为百分比或百分点。复核门槛在《实验口径》中预先给出。
