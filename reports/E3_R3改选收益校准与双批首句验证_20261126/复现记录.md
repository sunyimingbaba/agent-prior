# 复核记录

原始采样在学校 RTX 5090 的私有挂载 /private/AGSE_E3_1_rebuild_20261112/r3_switch_gain_20261126 完成。两批首句清单分别含 122、148 张图，包含原始图像标识与像素摘要、所属自然图对、首句、其他人工配文、场景工具反馈及随机数。每份权重每图运行两个八候选组和一条独立贪心。原始轨迹与冻结 CPU 检索器的 768 维输出由逐文件摘要关联，每个种子独立归档。所有评估只在本图选择过的同一组候选间比较；同分者等权。[采样清单](inputs/real_roster.json) · [划分与输入锁定](inputs/real_lock.json)

开发样本为上一阶段 204 张图，按自然图对分五折。同一张图的两种输入、两套权重和所有留句在同一折。主模型在原始首句和场景名样本上训练，按开发首句的跨折预测提名。与旧 R3 比较使用同折重拟合的旧评分参数。正式预测分别排除输入首句与重复句、轮流留出另一条正确句，将同图所有已知正例从负库屏蔽。计算奇数负库的训练可见分数、偶数负库的留出 MRR。D/E 两种留出措辞的二选一正确率是主要细节读数。[开发选型细则](开发选择细则.md) · [主模型提名](inputs/提名.json) · [配文近邻模型提名](inputs/配文预测提名.json)

两个新增预测程序均复算了原首句面板。在线 RFPO 需要在学校服务器上运行相同的奖励。当可见配文一致时，在 368 个开发八候选与留句组合上，独立实现与离线原程序的赢家集合逐项相同；手工导出的树结构与原预测器的最大数值差记录在[等价性核对](results/online_parity.json)。F/G 完全留出的文本由同一个冻结文本编码器计算，检查了 108 条文本的 token 唯一性及其与既有 A 至 E 文本的分离。[附加措辞](inputs/独立措辞.json)

在含历史各阶段真实资产的仓库中，从本阶段目录依次运行以下命令。若从 GitHub 检出，先将两个采样归档分别解压到 records/real/a 与 records/real/b。代码依赖本机的 NumPy、PyTorch、scikit-learn 及历史冻结检索代码。正式数值按图平均留句、采样组和两个种子，以自然图对重新抽样。

```sh
python3 -B code/study.py fit history78 history98
python3 -B code/neighbor.py fit history78 history98
python3 -B code/study.py v122 v148 merge
python3 -B code/neighbor.py v122 v148 merge
python3 -B code/new_phrases.py
python3 -B code/choice_audit.py
python3 -B code/pair_audit.py
python3 -B code/decision.py
```

实际 RFPO 各组从种子对应的同一冷启动权重开始。学校服务器上在本阶段目录执行 `bash code/pilot_queue.sh`，逐组保存权重、优化器、每步的候选动作和奖励赢家，以及每张正式评估图的一次先验。将模型完成凭据和步骤放回 models/、推理输出放回 evaluate/ 后，在本机运行以下核算。实际权重与优化器另存于 /Users/botlv/cup-deploy-assets/e3-switch-gain-20261126/models，每组逐文件校验信息见结果目录。每个单次推理归档以模型命名，解压到 evaluate/ 下对应目录即可还原。冻结 R2 的参照来自上轮在相同软件和读出器组合下保存的逐图输出。

```sh
python3 -B code/pilot_results.py
python3 -B code/pilot_audit.py
python3 -B code/pilot_extra.py
```

开发图预筛使用实际首句存档。运行 `python3 -B code/training_opportunities.py` 复算两份 R2 之间的异组复核，运行 `python3 -B code/make_cold_roster.py` 重建 13 个入选图与对照图的匹配。将 cold/inputs/ 与采样程序放到本阶段服务器目录，执行 `bash code/cold_queue.sh`。两份冷启动权重和像素摘要逐个核对后，再以 `python3 -B code/cold_analysis.py` 复算实际训练赢家及留句读数。冷启动的每个种子归档可解压到 cold/records/real/ 下对应种子目录。[筛选与匹配的约定](冷启动训练图预筛复核.md)

为核对配对训练在同一次更新上的数值波动，服务器执行 `bash code/repeat_queue.sh`。每份种子分别在全新进程中重做第一步，将动作、先验、优势、梯度和权重摘要写入 numeric/。原 24 步结果和确定性单步检查使用各自的目录。[单次输出的补充核查](单次输出补充核查.md)
