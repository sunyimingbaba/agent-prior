# R3 对每次改选的收益预测

固定部署 R2 及上轮校准 R3。检验在同组普通首选已确定的条件下，学习预测“换成这个候选会使未见细节或正确配文变好还是变差”是否更准确。开发图沿用 204 张训练划分图与原自然图对五折，所有参数和规则在新首句组评分前确定。训练选择侧使用输入首句及去重的其他可见配文、奇数负库、经标注的训练细节措辞。轮流用 A/B/C 中两种作为输入，第三种作监督；留一条其他人工配文，在偶数负库计算真实倒数排名变化。D/E 与新首句结果全程留作评价。输入首句的索引用于计算可观察的匹配强度，留句与同图其他已知正确配文均从负库排除。

预设比较两类预测器。第一类用带收缩的线性模型，第二类用浅树学习候选变化与原首选置信程度的关系。均直接学习候选相对普通首选的留出正确率、正负分差和配文倒数排名变化，图像、种子、输入条件、采样组和轮流留句等权。候选改选与否以及同分分配使用冻结的一致规则。在开发图对五折的预测上选择排序参数，兼顾细节与普通配文。开发选择只看 A/B 预测 C 的跨图结果。正式分开报告同样两种措辞，以及增加 C 后三种措辞两两组合的预测结果。留出 D/E 不参与选择超参数。普通首选、原校准 R3 与新规则在同组八条中比较。

另采两个首句面板。第一批取历史 guard 全部 122 张图，第二批取多数配文面板全部 148 张图。均与开发 204、既有留出 78、先前 98 图及正式 UCM 面板按解码像素身份分开，整自然图对互斥。两批历史上均有场景输入记录；该输入下的历史读数只作参考。本次各图给实际第一条人工配文，以既有两份 R2 各生成两组八条与一条贪心；新采样独立保存。每图至少两条不同于首句的正确配文才进入留句评价。

主看新首句两批逐批及合并的 D/E 正确率、留句 MRR，区别于整库 mR。先在第一批看已锁定方案，再在第二批原样检验，不按第一批调整主方案。以普通参照计两项增量，另直接与上轮 R3 比较。明显的候选改进要求合并后相比上轮 R3 至少一项配对 95% 区间下界大于零，另一项点估计不降，两批主改善方向一致，并同时核对对普通选择的收益。严格区分候选结果与新图单次模型效果；达到候选标准后检验一次输出。若主方案未兑现，则用已有材料追查误选或开展另行登记的实验，注明重复使用过的图。区间以完整自然图对为单位重采样 20,000 次，等权平均两个种子。
