# E3 两小时实验记录

UCM 的海滩图 `374.tif` 里，白色浪带很窄。在种子 a 的一折检验里，R3 从 16 条原场景候选中选出的先验，让冻结检索器把一句未参与打分的正确配文“白沙、绿水的宁静海滩”排到第 5，三种细节说法答对两种。把候选输入改为“岸边的浪带有多宽”，选中先验后，正确配文到了第 1，细节答对三种。两种输入都保留了所有同分赢家，在这张图上各自的赢家给出相同名次。这是一个有效的具体例子。[逐候选名次与原句](results/beach_example.json)

## E3-1 用奖励挑同图候选

“好候选”同时满足两件事。第一，冻结检索器把另一条正确的同图描述排得比原场景下的贪心先验更靠前。第二，它在未参与奖励的三种细节措辞上答对得更多。两项都要求严格提高。每张图有几条描述，就轮流留出可用的非首句；先在图内平均，再配对统计。“有机会”计算 16 条里至少有一条达到标准的比例，“选中”计算 R3 最终选到这种候选的概率，分母保留所有纳入的图、留出句与种子。

两批图都显示，原场景与中性细节问题各采八条，能让好候选更常出现。147 图从 23.47% 到 26.09%，增加 2.62 个百分点，95% 区间为 [+0.60, +4.84]。98 图从 18.92% 到 23.36%，增加 4.44 个百分点，区间为 [+1.62, +7.50]。R3 的最终选择在两批之间不同。147 图从 10.80% 到 10.79%，98 图从 5.38% 到 8.79%。把 16 条全部换为问题时，第二批达到 13.84%，第一批是 10.40%。按主实验事先登记的规则，两种提问来源均未进入 RFPO 短训。[第一批](results/first.json) · [第二批](results/second.json) · [入围判定](results/nomination.json)

候选来自每图的 R2 权重采样，R3 负责评选。R2 先看正确普通描述比普通负描述高多少；原多描述 R3 保留 R2 赢家作参照，用两条同图描述的检索排名设门槛，再用困难负例区分细微差别。比如“窄白色浪带／宽白色浪带”是奖励看到的训练措辞 A，验收使用其他说法 C/D/E。训练方向诊断中，给高 R3 奖励的候选略微增加抽取概率，相比同组 R2，第一批的细节局部变化率多 0.0258，第二批多 0.0103，后者区间跨零。这里计算的是现有候选的概率变化，单次部署结果另列。[训练信号定义](训练信号核查口径.md) · [两批训练信号](results/signal_second.json)

按同一批十六个原场景候选直接比较，147 图中随机选一条、R2、R3 的双项选中率依次为 6.33%、9.68%、10.80%。98 图依次为 4.24%、4.83%、5.38%。R3 相对 R2 的增量分别为 +1.12 和 +0.55 个百分点，两批区间均跨零。98 图全提问候选中，R3 相对 R2 从 12.78% 升至 13.84%，差值 +1.06 个百分点，区间 [+0.20, +2.16]；147 图全提问的差值为 +0.67 个百分点，区间 [−0.81, +2.24]。这使“困难负例能帮多少”可以和“提问能提供多少好候选”分别核对。[147 图奖励对照](results/prompt_reward_first.json) · [98 图奖励对照](results/prompt_reward_second.json)

两批普通检索图库还独立检查了图检文与文检图。混合来源相对原场景的平均召回率 mR 分别变化 +0.20、+0.55 个百分点，两批配对区间均跨零。给普通配文门槛再加上文检图方向后，原场景组相对原 R3 的 mR 分别变化 −0.07、+0.56 个百分点，区间也跨零。[整库第一批](results/gallery_first.json) · [整库第二批](results/gallery_second.json) · [双向门槛](双向普通配文奖励口径.md)

## 首轮探索与奖励赋分

发现批 147 图上，历史整套采样设置的双项选中率为 5.58%，本轮整条轨迹自由探索为 10.80%。在 98 图上，这两种历史设置对应 7.04% 和 5.38%。这两次历史比较还同时改变了第三轮和随机流，因此另设固定首轮与自由首轮的因果对照。[发现批历史设置](results/historical_timing_first.json) · [98 图历史设置](results/historical_timing_second.json) · [受控比较口径](首轮探索复核口径.md)

## E3-2 新图只生成一次

固定原 R2，先由场景分类结果自动选一个中性问题，再为每张新图生成一次先验。UCM 210 图、1,050 条配文的双向平均召回率从 **55.89% 降至 48.65%**，配对差 −7.23 个百分点，95% 区间 [−10.38, −4.11]。两个权重分别下降 7.42 和 7.05 个百分点。只用 833 条不同于本图输入首句的配文检索，差值仍为 −7.59 个百分点，区间 [−10.61, −4.52]。126 图的细节正确率从 61.90% 到 60.98%，差值 −0.93 个百分点，区间 [−4.89, +3.04]。保留原 R2 的单次生成方式。这个结果说明，训练候选池中出现过好答案，并不足以说明每张新图加同类问题就会检索得更好。[单次生成与逐图基线复算](results/independent_device.json) · [两种配文图库](results/device_ucm_gallery.json)

RSITMD 沿用历史可核对的 448 图、2,240 条配文。两套 R2 权重的双向 mR 从 30.70% 到 27.17%，下降 3.53 个百分点，配对 95% 区间 [−5.37, −1.72]。仅比较非输入配文时，446 图、1,739 条配文的差值为 −3.71 个百分点，区间 [−5.60, −1.84]。UCM 与 RSITMD 的变化方向一致。[跨域结果](results/device_cross_both.json)

## R3 把好候选漏在哪里

对原场景中“已有双项改善候选、R3 最终错过”的情况，147 图有 76.6%、98 图有 73.2% 在普通配文门槛处分出了优先级，所有好候选都落在低优先级。直接去掉门槛，147 图的留出普通配文 MRR 下降 0.0354，95% 区间 [−0.0560, −0.0172]，细节正确率增加 5.02 个百分点。98 图的普通 MRR 下降 0.0293，区间 [−0.0617, +0.0004]，细节变化 −0.47 个百分点。门槛确实会挡掉好先验，同时保护了部分普通检索表现。下一次奖励实验值得检验门槛附近的候选能否用连续扣分保留竞争机会，两项终点仍分别验收。[漏选归因](results/missed_opportunities.json) · [147 图去门槛](results/without_gate_first.json) · [98 图去门槛](results/without_gate_second.json)

## 数据范围

主实验的 148、98、122 图属于 UCM 训练划分，各图组按实际像素排重。单次细节评价覆盖 63 对、126 张验证或测试图；普通检索使用 210 张测试图和 1,050 条配文。其中 106 张图同时出现在细节面板和普通检索图库。这些历史评价面板已用于多轮对照。所有逐图记录、实际覆盖和配对区间见[逐项数值](逐项数值.md)，环境与程序见[复现说明](复现.md)。

## 时间窗口内的最终判定

98 图只改变 Agent 的第一个动作能否探索。固定首轮与自由首轮的双项选中率分别为 4.37%、5.38%，配对变化 +1.01 [-0.88, +3.07] 个百分点。有好候选的机会从 10.20% 到 18.92%。细节变化 +0.96 个百分点，普通 MRR 变化 -0.0047。原口径 CPU 完整复算。[配对数据](results/controlled_timing_second.json)

122 图只改变 Agent 的第一个动作能否探索。固定首轮与自由首轮的双项选中率分别为 4.81%、6.07%，配对变化 +1.25 [-1.03, +3.56] 个百分点。有好候选的机会从 12.53% 到 14.55%。细节变化 -2.67 个百分点，普通 MRR 变化 +0.0276。独立设备复算，原口径 CPU 仍在核对。[配对数据](results/device_timing_third.json)

将同场景且标注细节相反的两张图互换先验后，再比较提问对“用回本图先验”的影响。该细节优势相对原场景在两批分别变化 -0.45 [-5.41, +4.17] 和 -3.40 [-7.99, +1.02] 个百分点。[逐组对照](results/device_swap.json)

另用固定权重 a 在 126 图上检验每图随机生成一次。贪心细节为 61.90%，两个独立单次运行分别为 58.20%、57.67%，合计变化 -3.97 [-7.28, -0.53] 个百分点。该补充结果覆盖一个权重的细节面板。[单次随机生成](results/device_stochastic_seed_a_primary.json)
