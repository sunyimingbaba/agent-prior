# 实验复现与文件导航

本轮使用学校 RTX 5090。服务器上的本轮目录是 `/private/AGSE_E3_1_rebuild_20261112/source_transfer_2h_20261125`，沿用 `/private/AGSE_E1_20261110` 内的离线模型、数据和两个 Python 环境。Agent 生成和训练使用 `e1_prior_compat_20261111/venv`，冻结 CUP 读图使用 `legacy/env`。本机仓库的本轮交付独立成目录，历史目录均按原内容引用。结果用 0–1 比例储存，正文将准确率和召回率换算成百分数，将其差值换算成百分点。

## 图像、对照与评价

- [主采样口径](实验口径.md)与[固定清单](inputs/lock.json)记录两批 UCM 训练图和配文分工。第一批 148 图中 1 图去重后只有两条配文，保留其所有生成记录，147 图进入比较。第二批原有 142 图，已有问题表覆盖其中 98 图。每种来源、每图、每种权重生成两批八条；混合来源交换两批位置后取平均。R3 总分最高者并列时平均。C/D/E 是独立细节措辞，普通图检文在当折从未用于打分的正配文和另一半负描述上评估。
- [首轮受控方案](首轮探索复核口径.md)与[锁定记录](inputs/prefix_lock.json)记录第二批 98 图、第三批 122 图。固定首轮从当前策略执行真实贪心。再发生工具调用时，两组继续抽样的随机数、真实反馈、温度和停止条件一致。新旧历史采样还改变了第三轮和随机流，结果单列。对照报告的相同成本指每图十六个候选位置，实际生成词元另存。
- [像素查重](results/pixel_overlap.json)覆盖训练、开发和评价集。三批候选确认图像的 RGB 哈希互不相交，均与 24 张短训图、126 图细节评价和 210 图官方检索分开。问题开发 108 图全部属于用于搭建自动提问规则的 168 张历史训练图。普通测试图与细节面板共享 106 张图，两项任务使用不同输入和评价目标。多轮研究反复检查过这些评价面板。
- [单次部署](单次部署核查口径.md)冻结两份既有 R2 权重。只用历史训练图建立“场景工具分类→中性问题”映射，有可用映射时增加一次分类。普通 UCM 检索用图像和第一条配文生成缓存，两个方向都在整库排位。细节评价输入为同图对相同的场景提示，检索器比较正确细节与反向细节。跨域沿用历史可核对的 448 图 RSITMD 子集。[跨域与非输入配文协议](跨域与非输入配文核查口径.md)
- 置信区间来自 20,000 次配对重采样。候选实验和细节面板按自然图对，官方图库按图，将两套固定权重在每图的表现等权计入。图库召回先用完整图库计算，再按查询图聚合与重采样。同一图内的候选和三种措辞没有当成独立图片扩大样本量。

## 从生成到复算

1. 学校服务器用 `code/run.sh` 生成两批来源并由两个 CPU 分片投影。`code/prefix_queue.sh` 生成首轮干预，两组均调用同一真实工具。每臂保存逐图状态、动作词元、输入、工具结果和模型权重摘要。远端第一次来源运行在首个完整批次的清单写出位置遇到路径类型错误，`code/resume_first.sh` 核对并复用已完整保存的逐图文件，再续跑剩余组。下游按清单逐图重新验证。完整原始轨迹本机以 `records/<批次>/<种子>/trajectories.tar.gz` 保存。
2. 本机在这个报告目录运行以下脚本。它们使用同一仓库此前交付的冻结文本特征、排名实现和原始清单。组内统计在正式分支上二次对照分数实现；整库不确定赢家对双向召回的影响通过精确离散概率计算，小型穷举图库验证该实现。

```sh
for group in first second
do
  python3 -B code/report_scores.py "$group"
  python3 -B code/reward_direction.py "$group"
  python3 -B code/gallery.py "$group"
  python3 -B code/bidirectional_reward.py "$group"
  python3 -B code/when_to_sample.py historical "$group"
done
python3 -B code/report_scores.py nominate
for group in second third
do
  python3 -B code/when_to_sample.py controlled "$group"
  python3 -B code/attribute_exploration.py "$group"
done
python3 -B code/when_to_sample.py decide
for group in first second third
do
  python3 -B code/reward_resolution.py "$group"
done
python3 -B code/reward_resolution.py decide
python3 -B code/data_overlap.py
```

3. `code/auxiliary.sh` 管理单次自动提问和成对换先验，`code/replay_sources.py` 用独立的动作与对数概率采样实现重放固定图对。部署端有完整输出后，以 `code/single_scores.py`、`code/transfer_scores.py ucm` 和 `code/transfer_scores.py rsitmd` 重算。单次随机生成以 `code/stochastic_queue.sh` 与 `code/stochastic_scores.py` 重算。每图每轮只允许一条实际轨迹，两个随机轮次分别组成整库，再对两个结果取平均。
4. 训练资格由 `results/nomination.json`、`results/prefix_nomination.json`、`results/resolution_nomination.json` 中的独立规则决定。入围时才运行 `code/train_rfpo.py`，保留逐步奖励、真实动作、组内优势、重放误差和末步 LoRA。训练初始权重固定为原实验的两份 R0。可比终点由 `code/prefix_learned_scores.py prefix` 或 `resolution` 逐项核对。服务器保留续训状态，本地大型权重另存于用户模型资产目录。完整产物及其实际完成情况见本轮实验结果。
