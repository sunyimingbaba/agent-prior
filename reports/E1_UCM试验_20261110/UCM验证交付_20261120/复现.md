# 冻结验证实验复现

GPU 工作目录为 `/private/AGSE_E1_20261110/e1_ucm_validation_delivery_20261120`，上轮实验目录为同级 `e1_three_dimensions_20261120`。使用项目原有 Python 环境 `/private/AGSE_E1_20261110/legacy/env/bin/python`。六个设置各自的 `outputs/<method>/settings.json` 给出检查点路径、权重 SHA-256、锁定标签哈希、特征哈希、GPU 和 torch 版本。还原时保留目录相对关系。实验包已包含冻结输入和保存的向量。

1. 候选来源为 UCM 原验证 Arrow 及上轮锁定清单。`code/prepare.py <val.arrow> <上一轮目录>` 绑定 RGB 哈希、场景标签和原描述。图像盲审输入是 `review/blind.tsv`、`review/extra_blind.tsv` 及对应的 10 张图版。独立读图记录在 `review/blind_decisions.tsv`。`code/lock.py` 根据两侧一致性和歧义标记生成最终 `inputs/cases.json`。
2. 在私有服务器运行 `bash code/run_priors.sh` 生成三种查询条件的先验。运行 `bash code/run_scores.sh` 使用冻结模型比较三句。使用同一 Python 环境、UTF-8 编码执行 `code/priors.py AGSE_original` 逐图回放原始首句。仓库不包含分发模型权重，实际权重在私有挂载中。每次评分都校验检查点与输入。
3. 在本地本目录的同级保留 `三类细节基线_20261120`，运行 `python3 code/analyze.py` 以 NumPy 双精度重算并核对旧分。随后运行 `python3 code/overlap.py <UCM Arrow目录>` 和 `python3 code/sensitivity.py`，后者生成剔除整对后的表。`python3 code/case_figure.py <val.arrow>` 绘出案例。
4. `code/blind_text.py` 和其 `--original` 选项分别导出两批最终文本的打乱版本。归档的 `review/text_votes.tsv` 留存独立判读。历史首句回放组的待人工判读表仅有表头，所有最终字符串均为空、仅协议残片或仅标点。`python3 code/text_summary.py` 逐项比对缓存源 SHA、原生解码、正确方向与判读表。

数值评分的复现从已锁定输入开始即可。像素盲审和语义判读属于研究标注，用原始表和图版复查。场景标签设置的数据中保存所有余弦值，主报告只对其使用正负两句。上轮四个主方法各自的系统设定、检查点来源和版本映射见[基线来源](../三类细节基线_20261120/基线来源.md)。

初次启动在第一张图生成前缺少 Path 导入而退出，修复后从零运行。首次启动日志与返回值保留于 logs/initial_launch.*。priors、scoring、replay 三个正式运行分别返回 0。原项目的载入器打印了图像处理器默认值和分词正则的版本提示，本轮沿用历史设置，全量历史回放另以逐元素一致性核验。源模型和软件版本的现场校验见[运行环境](运行环境.json)。

报告分组由 code/dimensions.py 读取评分前盲审指出的储罐阴影类别。冻结评分输入仍保留最初的分类。分项结果同时导出初始及更正分组。文字语义判读另给出对 T111、T215 两项解释差异的敏感性统计。
