# 双输入同预算 RFPO 复现记录

本轮训练和单次推理使用学校 RTX 5090。项目文件位于服务器私有挂载目录 `/private/AGSE_E3_1_rebuild_20261112/dual_input_rfpo_20261126`，Agent 运行环境为 `/private/AGSE_E1_20261110/e1_prior_compat_20261111/venv/bin/python`。冻结检索器训练侧评分沿用原 CPU 读出环境。普通正确句、奇偶负库划分和留出 C/D/E 正反句沿用前序实验。本轮新建目录保存脚本及结果。两份冷启动权重、源评分代码、训练清单和主要数值实现的摘要见[输入锁定清单](inputs/lock.json)。

每个训练步在反向传播前保持同一份权重处理两个八候选组。每组各走一次自己的贪心参照，分别生成真实图像先验、计算组内优势，两组权重各占一半，然后统一裁剪梯度并更新一次。CPU 历史评分接口要求每次固定输入 17 行，八条候选向量在送入时复制一次，程序逐项核对复制行得分相同，计算奖励和梯度时只保留原八条和一条贪心参照。每 4 步保存可恢复状态，各组均取末步。验证包含第一步实际采样路径、困难得分及普通分数与同输入条件对齐。[训练入口](code/train_dual.py) · [奖励函数](code/strict_reward.py) · [训练审计](code/audit_training.py)

一份模型对一张图和一种提示只运行一次贪心。每条记录含原始图像摘要、输入提示、权重摘要、动作与反馈、最终被检索器使用的 Agent 状态和归一化视觉向量。按面板另存特征矩阵，逐项核对归档中图像身份、提示与特征。普通整库指标使用基准原有的并列名次规则。78 图与 64 图的普通配文评价去除首句和重复配文，在偶数负库上算平均倒数排名；106 图使用正式全库其他正确配文。文件保留每条配文的读数以配对计算胜负。[UCM 单次推理](code/evaluate.py) · [RSITMD 单次推理](code/cross.py) · [逐图打分](code/dual_scores.py)

从本报告目录运行以下命令可使用已保存结果复核主要数值。相对路径依赖仓库内先前各阶段的可追溯记录。

```sh
python3 -B code/check_design.py
python3 -B code/candidate_gate.py
python3 -B code/audit_training.py
python3 -B code/dual_scores.py
python3 -B code/transfer_results.py
python3 -B code/dual_scores.py reference

```
