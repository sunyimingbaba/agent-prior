# 普通描述门槛实验复现

计算目录为学校私有挂载 `/private/AGSE_E3_1_rebuild_20261112/caption_gate_20261125`。原候选由前两个问题实验生成。本阶段不运行 Agent，用冻结的 CPU 版 CUP 取回与每个候选隐藏态对应的图像特征。`code/read_features.py` 对源隐藏态、图片、记录摘要和权重逐图核查，保存两个面板各两个权重的向量与来源摘要。另一个 142 图面板直接读取已有的图像特征归档，其 SHA-256、生成与读出依赖由历史归档读取器核查。保留此前相关报告的目录结构。

本地从各特征重算真实文本相似度。每条同图非首句轮流留作目标，负图库按词元哈希切分。倒数名次遇到并列，对所有可能名次的倒数用分数精确平均。门槛的普通信号和 R2 赢家的门槛均值用有理数比较，避免舍入产生假性先后。候选级预测打平给半分；若整折目标名次全同则该折从排序一致率分母跳过。其他检索读数覆盖所有图。每份图像、种子记录先按折平均，再按图聚合两种子。条件指标在每图等权的基础上用实际出现机会的折数比例加权。区间按自然图对配对抽样。

在本报告目录使用 PyTorch、NumPy 和 SciPy：

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python3 code/run_stage.py development
python3 code/run_stage.py repeat
python3 code/run_stage.py transfer
python3 code/verify.py
python3 code/diagnostics.py
```

提名文件记录开发结果、实验口径与代码摘要，复核集入口检查摘要通过才计分。每个面板的 `records/*_folds.jsonl.gz` 记录每折留出的正例词元序列索引、可用配文、各门槛优先候选与最终赢家。原问题实验的普通读数是多条留出配文中最好的一条，本实验轮换评估每条配文；旧口径使用原来的负图库和参考句单独复算作兼容性核验。配文选择只使用当折训练侧的文本和冻结文本向量。调换负库时原 R2 分差和普通门槛也在调换后的训练负库重算。
