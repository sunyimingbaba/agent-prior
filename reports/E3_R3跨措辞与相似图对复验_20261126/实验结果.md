# R3 在留出措辞上的候选选择复验

固定 R2 的两份权重和已保存的候选后，校准过的 R3 在两批独立于拟合的场景图上更常选中能分清细节的候选。两批合计 269 张可评价图，留出细节正确率从 56.20% 提高到 57.20%，增量 1.00 个百分点，按 135 个自然图对配对重采样的 95% 区间为 [+0.43, +1.61]。同一候选的其他正确配文 MRR 从 0.39122 变为 0.39077，差 −0.00045 [−0.00343, +0.00252]。两批的配文排名变化方向不同，按实验口径本轮停在候选选择阶段。[校准结果](校准结果.json)

## 困难奖励怎样改变选择

普通选择按可见正确配文在检索库里的平均倒数排名，给每组八个候选排序。先试了两个直接的改法。一个要求同一细节的两种措辞 A、B 都判对且分差都提高，另一个用同一事实正反两侧的其他图对验证细节方向。开发集 204 图首句输入中，前者让留出细节提高 0.92 个百分点，留句 MRR 下降 0.00157。后者细节下降 0.51 个百分点，MRR 下降 0.00214。前者在另外 78 图首句上细节差 −0.09 个百分点，在 98 图场景输入上为 +0.37 个百分点，两批的留句 MRR 都回落。两条直接规则均未提名。[第一步口径](实验口径.md) · [第一步逐项结果](结果.json)

第二步仍用这 204 张开发图。先让两个小型评分模型分别估计，同一组里的候选能否同时改善细节和普通检索。输入有 A/B 两种措辞下的正负分差、正确配文的排名和相似度，以及它与高分负配文的分差。两个模型分别从第三种措辞 C 的真实细节分差和留出人工配文的真实排名学习。若两个预测都比普通首选更好，就改选二者较小的标准化增量最大的候选。其余情况沿用普通首选。开发交叉验证按自然图对分折。最终评分参数在读取本轮 148 图与 122 图的验证结果前写入文件。两个验证端点用未参与拟合和挑选的 D/E 措辞与轮流留出的真实配文。[第二步口径](第二步口径.md) · [评分参数和开发分折](锁定评分参数.json)

下表均为同一批八候选、同一输入下相对普通首选的变化。净胜出指细节与配文排名同时改善的频率减去同时下降的频率。MRR 使用 0 至 1 的原始尺度，两个百分数指标以百分点计。区间以自然图对为单位配对重采样 20,000 次，先在图内汇总，两个既有种子等权。

|---|---:|---:|---:|
| 204 图首句，开发集按图对交叉预测 | +1.26 | +0.00674 | +1.17 |
| 78 图首句，本轮既有诊断面板 | +0.34 [−0.90, +1.65] | +0.00183 [−0.01066, +0.01205] | +0.50 |

两批场景图来自不同的历史训练划分面板，均与 204 张开发图、78 图、额外 98 图及正式 UCM 面板按像素身份分离。148 图的 453.tif 去重后可用的其他正确配文不足两条，无法同时用一条选择和另一条验证。两个场景面板合并时两个种子的细节增量分别为 +1.07 和 +0.92 个百分点。首句面板两个种子的细节增量方向也相同，但该面板区间包含零。第一步用 C/D/E 检验。第二步用 C 提供开发标签，表中细节结果均来自独立的 D/E。[逐组证据，148 图](校准_148.jsonl.gz) · [逐组证据，122 图](校准_122.jsonl.gz) · [首句复核](校准_78首句.jsonl.gz)

保留同一模型输入，仅按配文排名预测挑选，作为第二步消融对照。要求细节预测也改善后，合并细节正确率额外提高 0.78 个百分点 [+0.33, +1.24]，MRR 比仅按排名预测挑选下降 0.00503 [−0.00846, −0.00191]。这项消融衡量在选法中显式要求细节预测进步的作用，两个评分模型均可使用 A/B 特征。[消融结果](校准结果.json)

## 正确配文排名损失出现在哪里

对 147 图面板逐条拆解，−0.00359 的平均 MRR 变化中，−0.00265 来自普通首选已经把留出配文排第一的情况，约占本批净回落的 74%。其余情况合计贡献 −0.00095。122 图上同样存在约 −0.00314 的第一名损失，其他情况贡献 +0.00648，抵消后整体为正。这项事后分解使用评估时才可见的配文名次。后续可用开发图的可见配文检验，哪些候选适合保留已有第一名，再另采实际首句输入验证。此次还未训练新的 RFPO 策略，也未产生新的整库 mR。[按逐组文件独立复算的分解](逐项核对.json)

两个脚本依次运行即可复算第一步和第二步，再运行核对脚本从逐项文件重建合并差值。历史特征路径继承前序报告目录。

```sh
python3 -B 候选复验.py
python3 -B 校准复验.py
python3 -B 核对读数.py
```
