# 复现 UCM 同起点奖励短训

服务器工作目录为 `/private/AGSE_E3_1_rebuild_20261112/matched_policy_20261120`。使用 `/private/AGSE_E1_20261110/legacy/env/bin/python` 以及同一挂载内的历史 LoRA、Qwen2.5-VL、域内场景工具和 UCM 权重。在新工作目录建立 `logs`、`scratch/cache/torch/kernels`，复制本次的 code、inputs 和 review。原项目的训练/验证图文特征及重建代理图库路径见评分代码。正式测试集独立于本轮。

1. `python code/prepare.py <UCM Arrow目录>` 从前期像素核验的困难图对中选出 24 张训练图，按种子 50811 固定顺序。验证划分保留全部 210 张原图，另标记此前困难题未用的 76 张图。`code/detail_cases.py` 记录新题来源。独立像素裁决保存于 `review/detail_audit.json`，运行 `python code/seal_eval.py` 应用修正、剔除歧义题并绑定哈希。恢复同一实验可直接使用冻结的输入清单。
2. `bash code/queue.sh` 依次从历史部署 LoRA 启动 old、caption、hard 三组。每组 24 步，每步 8 条真实生成的轨迹，组内优势标准化。模型保持 eval 模式以关闭 dropout，启用 LoRA 反向传播。按照实际生成的每轮 prompt、token、重复惩罚和 top-k 分布逐 token 重放概率，对生成 token 计算梯度；真实工具返回的上下文不计入策略损失。每 6 步原子保存模型与 AdamW 状态，完整训练后保存可加载的 PEFT adapter。每组固定使用第 24 步。
3. `python code/probe.py` 从历史起点独立重放第一组样本，保留隐藏向量、实际代理名次、真假关系分数及原描述分差。`bash code/eval_queue.sh` 执行全验证集先验再生成、关系原图与旋转图再生成、冻结检索读出及统计。单图保存成功后可续接。脚本中的 base 是历史部署起点，old 是从该起点按原奖励追加短训的控制组。
4. CPU 可用 `python code/analysis.py` 从 `eval/<arm>/vectors.pt`、`text.pt` 和留存原始轨迹重算全部表格。计算时先对 391 个唯一描述 token 序列各求一次定序余弦，再展开为 1050 条原描述的归属。边界并列按等概率打破的期望处理。置信区间以源图片为单位，成组保留该图的五条描述或两种视图、同义句，20,000 次有放回抽样。整库区间反映给定图库下查询构成的变化。
5. 本地与服务器的 `policy_<arm>/adapter` 可直接加载。Git 中 `adapters/<arm>` 保存相对历史起点的无损差分。执行 `python code/adapter_delta.py restore <历史adapter_model.safetensors> adapters/<arm> <新建的输出文件路径>`，并配合同一组 `policy_<arm>/adapter/adapter_config.json` 加载。恢复脚本校验起点、每个分片及完整输出的 SHA-256。`resume.pt` 含最后一步的优化器状态，留在本地与私有挂载。

附加诊断可用 `python code/eos_reward.py <上阶段空间关系候选奖励核验目录>` 重算。代码在每幅图中比较“立即结束”轨迹与其他轨迹的奖励排序。另用 `python code/first_state.py <arm>` 固定读取每一策略第一次生成的隐藏态；主试验仍以自然生成到结束的缓存计分。运行 `python code/behavior.py` 汇总实际响应长度和真实工具调用。

历史起点的通用查询另在新进程中加载权重，并记录实际加载的 LoRA 参数指纹。在尚未生成 `scratch/replay_base_generic` 的工作目录中运行 `python code/check_base_generic.py` 可重复这项检查。210 张图的生成轨迹和 BF16 隐藏向量均与初次运行逐项一致。[逐图回放记录](review/base_generic_replay.json)

本机和服务器上的完整实验目录可用 `python code/manifest.py --verify` 核对。清单包含三套完整 LoRA 及优化器状态，Git 版本通过第 5 步恢复最终 LoRA。[完整文件清单](文件校验.json) · [双端校验记录](双端校验.json)
