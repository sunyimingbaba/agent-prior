# UCM 固定候选奖励调参结果

**当前保留真实图文项，细节项 25% 留作下一轮开发对照。** 只给场景名时，25% 细节权重提高了留出方向描述 B 的判对率，普通描述的排名略有下降。换成历史首句后，方向收益消失。预先登记的无格式筛选中，四档混合权重均未同时达到方向和普通检索条件。

复用 16 对、32 张 UCM 训练图。每张图在场景提示和历史首句条件下各有 8 条历史多轮候选，共 512 条。两个输入条件分别计算。场景提示下有 29/32 张图至少有一条 B 判对的候选，其中 21 张好坏混合。有 23/32 张图至少有一条候选能同时判对 B 和 C。历史首句的对应数字为 29、22 和 21。候选来自历史部署 Agent，所有结果均为已有训练图上的离线开发证据。

## 真实图文和方向细节分别起什么作用

只给场景名时，真实图文项优先挑出更有利于原生描述检索的候选。相对原 RFPO，留出描述的平均倒数排名提高 0.1030，16 对自然图配对重采样的 95% 区间为 [−0.0302, +0.2601]。留出描述的正负余弦分差提高 0.00854，区间为 [+0.00379, +0.01355]。换成历史首句时，真实图文项在 B 方向题上由原 RFPO 的 62.50% 降至 46.88%，差值为 −15.63 个百分点，区间为 [−31.25, −3.13]。真实图文项适合保留为普通匹配对照，方向效果要另外验证。

新配方表内均为无格式项，细节权重按两项图内平均秩计算。B 和 C 是同一方向关系的不同说法。普通描述移除了首句，并使用评分时未用的负例池。倒数排名为本轮固定图到文选择指标。25% 权重相对纯真实图文在 B 上提高 5.47 个百分点，图对配对 95% 区间为 [0.00, 13.28]，普通描述倒数排名变化为 −0.0161，区间为 [−0.0709, +0.0221]。改用历史首句后，两组 B 均为 46.88%，C 均为 56.25%。权重升到 50% 或 75% 时，场景提示下 C 的表现更好，同时普通描述分差进一步下降。选择效果与验收措辞有关。

储罐图 `1919.tif` 上，代理排名和真实图文分都选第 0 条，B 错、C 对。细节项占 25% 时，第 0、1、3、5 条并列，按均匀选择计，B 判对概率为 75%。权重升至 50% 时，第 1、3、5 条并列，均通过 B/C。这三条的隐藏向量相同，保留三次实际采样的频次。

## 格式分到底改了什么

原始 0.2 与原代理倒数排名相加时，场景提示下 15 张有合规和不合规候选混合的图里，12 张改选，B 上 2 张从错变对、4 张从对变错，整体下降 6.25 个百分点。历史首句下 3 张混合图均改选，B 上 3 张都从错变对。两个输入条件中共有 23 条候选触发格式分，未出现空标签实例。原规则允许空标签的事实来自代码，此批候选只能检验完整标签对选择的影响。

把内容秩统一到 0–1 后，另试加 0.05、0.10 和 0.20。对场景提示下的 25% 细节方案，0.20 使 2 张图改选，B 不变，C 多判对 1 张，普通描述平均倒数排名升到 0.421。倒数排名相对纯真实图文提高 0.0063，配对区间为 [−0.0624, +0.0719]。这两张改选图贡献了全部回升，历史首句下该组合的 B/C 表现仍与纯真实图文相同。25% 细节加 0.20 格式分属于探索性结果。

## 下一步判断

候选中经常能找到正确方向，直接给细节项加权的收益却随输入和措辞变化。下一轮优先在现有开发图上比较单一措辞和多措辞方向分，继续保留现有的单措辞 25% 方案作为对照。建议先用同图配对的方向分检验跨措辞一致性，仅在现有开发图上定配方，再用独立的新图验证普通检索能否保住、方向增益能否复现。此次未采新候选、更新模型或计算整库 mR。

复算时逐条核对了 192 条已发布的共用候选奖励秩及结束符标记，512 条候选的全负例池排名和分差也与原归档一致。运行 `python3 analyze.py` 可重算，汇总记录了输入哈希、库版本和 bootstrap 种子。
