# UCM 困难负样本措辞对照

复用前轮 16 对、32 张 UCM 训练图的 512 条候选。候选来自历史 Agent 多轮生成。冻结候选、真实图文分、普通描述正负例池和文本表征。统一关闭格式项以隔离困难负样本措辞的变化，保留带原格式项的历史 RFPO 作为参考。按实际采样频次保留候选，最高分并列均匀选择。

困难负样本是仅反转地物方向的描述。先对每种措辞计算正确句减反向句的余弦分差，再在同图 8 条候选中取平均秩，缩放到 0–1。两种措辞给分时取两套秩的等权平均。最终内容分由真实图文秩和困难负样本秩加权求和。

主对照只给场景名，固定困难负样本权重 25%，用 C 检查 A 单措辞、B 单措辞及 A/B 双措辞选中的候选。普通描述使用剔除首句后的正例及前轮留出的负例池。报告 C 的判对率及正确句减反向句分差，普通描述倒数排名及正负分差均逐图汇总。主筛选要求双措辞在 C 判对率上同时高于两种单措辞，且普通描述倒数排名与分差均达到纯真实图文的水平。再观察历史首句条件下方向收益能否保持。

补充比较 50%、75% 和仅困难负样本。轮换 A、B 作为验收措辞，另外两套措辞用于打分，比较增益是否依赖验收措辞。轮换只用于解释条件差异，C 的主对照保持原定口径。A/B/C 同属既有训练图和关系标签，C 曾在此前分析中使用，本轮仅衡量已有样本上的措辞迁移。

沿用前轮按源自然图对做 20,000 次配对 bootstrap 的口径。普通检索指标衡量固定候选的图到文选择。全部结果用于开发。
