# 冻结第二轮 R2 的独立复验

用上轮已经训练好的两组权重。普通检索的主比较为第二轮 R2 对第二轮 R1，同时检查相对未训练 R0 的增益。首轮训练 R2 是动作位置对照。两个种子分别推理，R0 验证 LoRA 的所有 B 矩阵均为零后共用。每项报告两个种子和种子平均差值。两个数据集分别排名与统计，UCM 是同域复验，RSITMD 是固定 UCM 检索器及工具的跨域检验。

按本地 Arrow 中 test 标记读取所有图，先对 UCM train、val 及两个新图库做解码 RGB 与尺寸完全相同的去重检查。按 UCM、RSITMD 顺序保留独立图，保留首次出现的同库图。UCM 210 张全部保留。RSITMD 452 张中 4 张与先前 UCM 数据像素完全相同，保留 448 张。各图五句原标注作为图库，第一句参与该图先验生成。锁定原权重、真实 UCM 场景工具、完整贪心流程、最多三轮、每轮最多 64 个 token 和同一 FP32 CUP 读出。主要指标是两个方向 R@1、5、10 六项的算术平均，采用既有并列分数处理。另看删去各图与生成输入 token 相同的描述后的结果。

属性题在查看本轮任何分数前，沿用上轮同场景自然图对及互换正负句的方式，目视选择有明确差异的 UCM 测试图，覆盖旧题中的颜色、地表、形状和方向等。以严格正负分差大于零算答对，并报告同图对两端都对的数量。主检索按源图、属性按互不重叠的图对配对重采样 20,000 次；固定图库，区间反映图像抽样的不确定性。检索同域收益需同时考虑 R1、R0；跨域和属性分别报告。若独立检验结果分歧，保留原始结论及各自的适用数据范围。

目视核对后锁定 25 对、50 张互不复用的 UCM 图。属性主读数使用全部 25 对，同时单列旧扩展属性题逐字复用的 8 对，另有 4 对复用更早的句子、13 对按相同规则新写。此前 36 题和本轮题目用同一打分规则。检索区间固定图库，额外按场景类别聚类检查 UCM 同类裁块相关性的影响。所有主比较、题目及正负标签在查看各臂得分前锁定。

另列一组更严格的属性诊断。仅保留两端喂给 Agent 的首句逐字相同的图对，查看这些图上判断属性的变化。UCM 测试集曾用于较早的下游检索实验和案例图，这次对照使用的是先前冻结的 E3 权重。RSITMD 使用同一套 UCM 权重和工具直接迁移。两个域都与本轮权重训练样本作开发后复验，不以当前结果再挑选训练步数。

## 样本来源与复算

源标注逐图对照了两份本地原始 JSON，两个测试划分中的所有文件名和五句原文均一致。UCM 的 21 类各 10 图；RSITMD 去重后涉及 31 个文件名前缀类别。四张跨库重复图都在 UCM 训练划分中。另用 SIFT 特征与几何一致性检查裁块重叠，UCM 港口图 1095 和 1096 有 41 个内点。敏感性分析去掉后者，按 209 图和对应的 1,045 句重建图库。筛查使用缩放到 192 像素的局部特征、至少 12 个不同位置、两侧覆盖均至少一成、内点比例至少六成。仍可能有相邻裁块或难以检测的重叠。原始文本编码上限为 61 个 token，本次 UCM 与 RSITMD 均无检索描述触发截断。

在本地用 code/manifest.py 和 code/check_sources.py 按原始 Arrow 及标注生成清单。code/make_attributes.py 使用上轮保留的 E1 原句生成本次目视配对清单。code/overlap.py 生成重叠筛查记录。服务器上的本轮目录为 /private/AGSE_E3_1_rebuild_20261112/after_tool_holdout_20261124。将 code、inputs 和原始 RSITMD 测试 Arrow 放到对应位置，创建 scratch 和 results，按 code/infer.sh 顺序生成先验；并行用 CPU 原环境运行 code/reader.py，并用 code/reader.py attributes 生成属性文本特征。code/finalize.sh 在所有特征就绪后归档、评分并独立复算召回。code/check_archive.py 可核对回传的逐图记录。两组模型权重仍在此前第二轮短训的目录，训练种子为 20261123 和 20261124。UCM 旧测试案例的使用情况见[历史案例读取说明](../../figures/qualitative_retrieval_diverse_20261017/README.md)。
