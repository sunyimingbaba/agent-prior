# 单次先验能否从相同奖励信号中学到改善

增设一个单次生成的机制对照，检验训练信号经过实际检索器反传时，原先验是否含有可用于两项任务的信息。冻结现有 R2 Agent 和 CUP，Agent 每图真实贪心一次，从其最终隐藏向量训练一个小型残差输出层，再将先验送入原冻结 CUP。这个实验改变先验输出表示，RFPO 策略更新另行记录。普通输入为图像原首句，细节输入为原场景短句。采用同一个输出层；推理只读 Agent 当前终态，不输入正确标签、额外候选、困难句或图库名次。

第一、第二批按原清单使用全部 148+98 图进行训练。第三批 122 图用于开发。新配对 94 图、原 142 图剩余的 44 图、原 126 图细节面板及原 210 图普通测试图库均用于冻结后的外部检验。跨库用 448 张 RSITMD 图，按既有协议核对。单套模型仅训练它对应种子的输出层。共享相同图序、初始值和训练预算，比较 R2 普通奖励与 R2 加 A/B 困难负例监督。另以无输出层的原 R2 为部署参照。使用图内普通首句以外的其余原始描述，按原图进行双向对比学习；同图附带的 A/B 只用于场景输入下追加真假细节的成对损失。训练时用同一冻结 CUP 求导。开发阶段在事先给定的小量训练轮次（1、3、6）中选择共同的进度，在冻结模型上同时比较两个训练臂。通过条件是开发检索 mR 和细节均高于无输出层，合格者选两项等权增量最高的一轮；若无合格者选合计最高的一轮并标记探索性。将测试两项、两个种子和所有预定面板完整报告。输出层对照的结果与 RFPO 单列。

在冻结的 94 图上新增目视配对和三种验收措辞，与开发图按 RGB 分开。其余面板曾用于以前的研究。若新层在测试普通 mR 和全新 94 图细节均有正的配对区间下界，再评估是否值得以该训练目标继续策略蒸馏；若仅单项改善，优先分析候选奖励与实际部署目标的差异。

输出层具体实现采用训练输入的前 32 个主成分，经训练集白化并限幅后，用一个零初始化线性层预测 3,584 维残差。每维的最大变化按输入的均方根幅度的 0.5 倍限幅。原状态输入不变时，零参数严格恢复原先验。每步取四个完整自然图对，普通双向损失在两种输入上等权，图库内按本图全部已知描述避免误罚。两臂均为 AdamW，学习率 0.015。困难负例臂额外加场景输入 A/B 平均的 softplus 成对损失，权重 0.75。冻结开发、训练代码和参数后再打开单次测试结果。
