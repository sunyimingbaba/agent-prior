# 同一回填上下文中人工改变第二轮细节真假

本项人工控制诊断只使用已完成的 C 批冷启动 A，以及 C 的原始 98 图、首句和自然工具回填上下文。每图两条第二轮回答仅在 A 题标注方向上不同，均使用同一英文答复外壳 `<answer>句子</answer>`，后接相同的模型实际结束词元。两个版本均使用 teacher forcing，按原生成实现取最后一轮预测结束词元前的最后一层隐藏态。先用 C 中真实生成、以同一结束词元结束且第二轮未再次调用工具的回答核对终态。至少四个不同图的完整词元路径纳入重放，按图像素摘要与槽位固定顺序选择。重放若有数值差，复核有关样本冻结检索器的排名与细节正确方向，必要时使用原批生成的缓存逐词元执行。在校准通过后读出人工控制结果。归档实际词元、结束词元、终态和投影。

主比较为同一图上真句减去假句。对 A/B 两题中较弱的真实方向分差报告均值差，并报告该分差给真句更高的图数及比例，并列计半。对未参与构造的 D/E 和 F/G 报告平均正确率差。对去重且排除输入首句的其他正确配文，使用原奇数负库及并列均分计算 MRR 差。另按原始源文件核对自然对两侧 A 题的真假句是否互换，完整互换图对单列。每图等权，以自然图对整对重抽 20,000 次，给出 95% 百分位区间。只在上述一种人工改动下读出，不调奖励、选法或策略。
