# 数据、采样与复算

原始图像、轨迹和模型使用学校服务器的私有挂载目录。该阶段目录为 `/private/AGSE_E3_1_rebuild_20261112/aftertool_joint_pool_20261127`。实验使用 RTX 5090。在 270 张有细节标注的 UCM 训练图上，使用图像与其真实首条配文。图像像素摘要与三个图库分别比对，覆盖先前的 24 张训练图、126 张细节图和 210 张正式检索图。两批复用同一批图，每幅图的五条配文逐项对照数据文件，场景工具反馈逐图重新计算。[像素分离核查](results/图像划分核查.json) · [采样名单](sampling/inputs/roster_lock.json) · [工具实际输出](sampling/feedback_verified.json)

采样沿用两份冷启动权重和上一阶段的工具执行程序。两份适配器文件摘要不同，历史核对显示两份起点的 LoRA B 均全零，历史 210 图的冷启动读出逐项一致。因此本轮检验的是相同初始行为下，换一批随机回答，机会能否再次出现。贪心首轮进入场景工具后，从真实反馈对应的前缀采八次第二轮回答。保留候选触发再次调用后的续写、最终状态、输出文本和采样概率。A、B 的候选随机数分别为 211000000、221000000 加上源数据行号的 1000 倍。A 名单依据该批全部候选一次锁定。下一步只读取 B 的首轮调用是否成功，确定可训练图和按像素摘要排列的顺序。B 候选评分前验证这两次封存的文件摘要。[采样入口](sampling/code/run.sh) · [名单与主检验计算](scoring/code/screen.py)

评分每次使用原生图文读出、原代理读出和封存困难奖金。原生库中，同图正确句均从负例中移除。R2 的输入首句对偶数散列负例取最难分差，其他配文的倒数排名在奇数散列负例上计算。每图合并重复配文。先平均 R2 同分首选候选的表现，再检查是否有候选能多答对细节、同时保持其他正确配文的平均排名。涉及相等的配文和并列首选按精确分数比较。保留 D/E 和 F/G 两组独立措辞用于复核。[冻结读出与奖金](scoring/code/pool_reader.py) · [输入来源摘要](scoring/inputs/manifest.json)

分数目录恢复后，运行 `python3 results/verify.py` 从代理名次、原生分差、两道题分差和逐句倒数排名独立复算两批共 540 份记录中的合格组。运行 `python3 留句核查/check.py` 重新生成逐图留句记录和区间。运行 `python3 旧记录复核/check.py screen` 复算在本轮评分之前从历史全流程候选锁定的名单，再以 `python3 旧记录复核/check.py compare` 统计新 B 批的结果。后两项分析不会改变筛图和启训条件。[留句复核口径](留句核查/口径.md) · [历史名单的口径](旧记录复核/口径.md)

正式推理向量生成前，另沿用上阶段已经实施过的 56 图 F/G 措辞复核。按上一阶段完全相同的图库、配对、措辞与读出重算，脚本仅把输入的四份模型输出和存放结果的位置指向本阶段。使用同一套预先存在的 56 图，为上一阶段和本阶段提供相同口径的补充指标。[复算入口](evaluation/code/held_wording.py) · [先前口径](../E3_R2逐候选分值与困难细节加分_20261127/analysis/新措辞复核口径.md)

从 Git 存档恢复逐图读数时，scoring/results/candidate_scores.jsonl.gz 每行对应一个图与一个种子。按记录的 seed、image 字段恢复到 scores/种子/图名.json 后，可运行留句和独立验算。采样压缩包在 sampling/ 目录下解包，得到 raw/a/ 与 raw/b/。

四份末步 LoRA 和恢复状态分别保存到服务器本阶段的 models/ 和本机 `/Users/botlv/cup-deploy-assets/e3-aftertool-joint-20261127/models/`。两地保存的四组文件各 6 份，含优化器恢复文件、权重、候选记录与训练配置。末步适配器逐张量与恢复点相符。四组训练日志、逐步原分、困难奖金和实际优势均可复核。正式输出按模型分包，新模型每包含 210 条逐图输出，历史两个 R0 和两个部署 R2 各重放 3 张锚点。[权重备份清单](training/权重备份核对.json) · [正式输出索引](evaluation/archives/index.json) · [原始轨迹归档复核](results/原始轨迹两地核查.json)
