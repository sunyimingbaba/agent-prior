# 固定图像像素检验先验携带的细节事实

使用已记录的真实首句及场景工具回填后八个自然候选，两个来源固定为 C 批 98 图 49 对与 D 批 114 图 57 对。同一自然图对的两侧属于同类场景、具有相反的细节标注。两个集合按像素不重叠，但都有研究使用记录。先逐候选把各自隐藏态放回原图，与历史 CPU 冻结检索器输出逐元素验证一致；再把每个隐藏态放到对侧像素上，用完全相同的检索器重新前向。只运行 CPU。既有双向困难奖励比较两张原图的原生融合向量，本轮在同一套像素上比较两组先验，像素在每次差分内固定。

对任一侧 i 及训练措辞 A、B 中的每一项 q，令 m(x,h,q) 为像素 x 和先验 h 融合后，对 i 的真句比 i 的假句多出的相似度。对本侧候选 h，分别在本图像素和对侧像素上求 m(x,h,q) 减去同一像素下对侧八个先验的平均 m，再将两项等权平均，得到 c(h,q)。因此对侧像素上的文本正负方向仍取 i 的标注。本候选的额外分数取 c(h,A)、c(h,B) 中较小者。两项都为正表示在两种措辞上、平均两个像素背景后，本候选比真实对侧先验更偏向本侧事实；两套像素背景各自的读数也分别保存。

每次暂时隐藏一条非首句真配文。用原 R2 组内最高分候选作为基准，并列首选等权。较低分候选首先须满足旧严格规则：A/B 答对数严格高于原并列首选均值，原图 A/B 较弱分差严格高于每个原首选，每条可见真配文倒数排名均不低于首选均值。该候选还须较小的 c 分差为正并严格高于每个原首选的 c 分差。然后仅在合格候选及原首选之间按较小 c 分差排序，重分配这些候选原有的 R2 分数，按原规则处理并列。不合格者保留原分。另按原实现重算原 R2 和旧严格 R3；不改变任何既有模型或训练奖励。

D/E、F/G 及隐藏真配文的倒数排名不参与选择。每次隐藏一条真配文、并列等权，求选中回答对 D/E、F/G 的图找正确句比例、在真实对图之间文找正确图的比例和隐藏真配文 MRR。另诊断在固定像素条件下，选中先验对 D/E 本侧事实相对对侧先验均值的贡献。每幅图平均措辞和留句，再按自然图对等权，固定随机数 281128，重抽 20,000 次求配对 95% 区间。

预先以新奖励相对旧严格 R3 的 D/E 图找正确句比率和隐藏配文 MRR 为主。98 图 D/E 点差须为正，114 图 D/E 配对区间下界须大于零，两来源的隐藏配文 MRR 和 D/E 文找图点差均须非负。同时，两来源新奖励相对原 R2 的 D/E 图找句点差须为正、隐藏配文 MRR 点差非负。通过后才在无首句输入下重新采候选，评估是否值得进入策略训练。未通过时保留反事实的机制读数。历史输入含首句，本项只检验已有八个先验之间能否选得更好。
