# 固定问题下的单次图像先验检索

检验相同训练起点和相同 24 图预算下，严格保护配文的 RFPO R3 相比原 RFPO R2 能否用一张图产生可复用的检索先验。模型为既有两个起点对应的四份末步权重。所有图、两个候选策略和两次初始化统一使用 “Describe the visible features of this remote sensing image.”。既有中性观察实验按图像属性选择问题，另附场景提示。本轮固定上述问题。沿用现有贪心工具协议的系统文本和固定港口示例，统一核对完整模板摘要。真实用户回合只含当前图像和固定问题。场景分类器按像素重新运行，逐图与历史反馈文本核对，仅模型真实请求时返回。生成名单仅保留图库、行号、图名、像素摘要、划分、反馈；文件名和行号只用于定位图像。记录实际用户问题、送入处理器的模板摘要、第一轮输入的词元摘要、各轮实际生成词元和调用。输出仍由同一冻结的原生检索器读取。

在固定 UCM 210 图各生成一次，106 张含细节标注的图检验 D/E 以及除原首句之外的其他正确配文 MRR。后者沿用旧协议的统计对象，所有配文均未输入本轮策略。主标准为 R3 相对 R2 的 D/E 配对差 95% 区间下界高于零，整库 mR 与 106 图其他配文 MRR 的点差均非负。报告完整图找文、文找图 R@1、5、10、各方向平均与双向平均。额外 164 图按原扩展图库报告相同双向读数、D/E 与可评图的其他配文 MRR。正式整库按 210 图重抽，106 张细节图按 53 个自然图对重抽，沿用随机数 20261125；164 图所有读数按 82 个自然图对重抽，沿用随机数 271127。每幅图先合并两个固定起点的成对变化，重抽 20,000 次，并列出两个起点的变化。保留旧首句输入的结果供协议内比照。
