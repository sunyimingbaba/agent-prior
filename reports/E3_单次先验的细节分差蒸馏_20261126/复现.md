# 单次先验分差蒸馏的复现记录

训练和评估在学校 RTX 5090 上依次运行。主实验目录为 `/private/AGSE_E3_1_rebuild_20261112/greedy_margin_20261126`，实际候选分差对照在同级的 `greedy_attainable_20261126`。两者沿用同一级目录里的原始 RFPO 训练与工具记录。Agent 使用 `/private/AGSE_E1_20261110/e1_prior_compat_20261111/venv/bin/python`。五个翻转案例另用原检索器环境在 CPU 上重新计算。运行所在目录及数据依赖由 [服务器入口](code/model_run.py) 和 [本地评分入口](code/local.py) 指定。

| 步骤 | 使用的材料与入口 | 核对内容 |
|---|---|---|
| 回看上一轮错误 | [诊断](code/diagnose.py)、[独立重算](code/reproject_five.py) | 两套权重逐图核对工具序列、原始反馈、末层状态和正反句分差 |
| 固定训练目标 | [教师选择](code/prepare.py)、[锁定清单](inputs/lock.json)、[可达性检查](code/feasibility.py) | 原始轨迹、两份起点、候选索引、训练与留出图、数值代码均有摘要 |
| 三组监督训练 | [训练](code/fit.py)、[队列](code/queue.sh) | 同一训练种子的三个条件从同一权重开始，各取固定第 24 步，逐步保存梯度范数与重放余弦 |
| 单条候选目标对照 | [目标生成](code/reachable_inputs.py)、[数值校验](code/check_targets.py)、[对照队列](code/reachable_queue.sh) | 使用同一候选、图像、图序、优化设置及冻结检索器，两个条件各跑两份起点 |
| 一次生成的评估 | [生成记录](code/evaluate.py)、[UCM 评分](code/margin_scores.py)、[逐题比较](code/changes.py) | 同图同提示只取一次贪心输出，正式普通检索与细节面板沿用历史数据和规则 |
| 训练图与跨库复核 | [训练图单次生成](code/fitcheck.py)、[训练目标短缺](code/fit_scores.py)、[RSITMD 生成](code/cross.py)、[跨库评分](code/cross_scores.py) | 在实际单次输出上比较末步与起点，跨库再分别评全部配文和排除输入配文后的排序 |
| 备份核对 | [UCM 核验](code/verify.py)、[RSITMD 核验](code/verify_cross.py) | 对每图校验图像、提示、权重和输出摘要，逐一比对归档中的视觉向量与评分矩阵 |

在保留仓库原有历史报告目录的环境里，可从本目录离线复算主要结论。下面两条分别使用逐项取大的目标与同一实际候选的目标。

```sh
python3 -B code/margin_scores.py
python3 -B code/margin_scores.py reachable
```

训练图复核、跨库评分和逐题核查使用下面的入口。复算正式端点只读已经保存的先验和检索文本库。

```sh
python3 -B code/fit_scores.py
python3 -B code/fit_scores.py reachable
python3 -B code/cross_scores.py
python3 -B code/cross_scores.py reachable
python3 -B code/changes.py
```

候选选择、训练监督、64 图留出评估和两个正式面板的分工见[主实验登记](实验口径.md)、[训练图复核登记](训练目标复核.md)、[跨库登记](跨库普通检索复核.md)及[同一候选对照登记](reachable/实验口径.md)。RSITMD 使用有图像及工具记录的原 448 图子集。跨库结果沿用 UCM 检索器。两份随机种子固定，区间反映图像或自然图对的配对重采样变动。
