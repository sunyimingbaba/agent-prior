# 复现这次方向诊断

本轮运行目录为 `/private/AGSE_E3_1_rebuild_20261112/coverage_transfer_20261120`，上阶段完整输出在同级 `paired_views_20261120`，运行环境指纹见 [环境记录](environment.json)。原始 UCM 私有资产和 Python 环境沿用 `/private/AGSE_E1_20261110/legacy`。本轮只推理，使用历史部署的 Agent LoRA 与 CUP。

1. 根据 [来源校验](inputs/source_receipt.json) 核实上轮训练图、候选覆盖和既有标注清单。使用 `code/make_sheet.py`、`code/prepare_labels.py` 可重新生成候选图页和题句。图库上的新增题目先做像素盲审，再以 `code/overlap.py <UCM Arrow目录> inputs/proposals.json review` 筛查同场景训练/验证裁块重合，`code/freeze_fresh.py` 取两次判断一致、指称清楚且通过筛查的样本。项目内运行 `code/source_inventory.py` 核对题图来源。正式测试划分保留。
2. 在独立的新目录复制 `code/`、`inputs/` 和 `review/`，创建 `scratch/cache/`、`results/`、`logs/`。在绑定环境内通过 `python code/lock.py train` 和 `python code/lock.py fresh` 核对已登记的输入及推理代码。新目录执行 `python -u code/run.py train` 及 `python -u code/run.py fresh`，每张图、每种提示和每个朝向生成 1 条贪心轨迹及 8 条温度为 1 的候选。逐图输出包括真实生成 token、工具结果、目标图先验、CUP 图像向量、两种文本编码器的文本向量和无提示词元的 CLIP 图像向量。跨提示采样槽位的随机种子匹配。
3. 每个朝向固定图像，分别用同图的 36 份先验，以及 16 张训练图历史贪心推理所得的外图先验重新读出 CUP 特征。训练目标剔除自身和同一反向图对的另一幅图，因此每图使用 28 份外图先验；新验证每图使用全部 32 份。普通检索覆盖原验证图库 210 张图、1,050 条描述，沿用之前每图第一条原描述或全图库通用提示生成的历史先验，逐张重新运行冻结 CUP。[运行实现](code/run.py) · [图库重放](code/gallery.py)
4. `bash code/aux_queue.sh` 等待主推理的任一分组完成后运行补充二选一与图库复验。可以单独执行 `python code/choice.py`、`python code/gallery.py`。直接二选一使用同一个历史 Agent，对每组正反描述交换 A/B 位置并读取首个生成位置的 A/B logits，分别输入原图、半转图及均匀灰图。保留 A/B 词元概率质量与全词表首选，便于核查答案格式。[补充方案](inputs/agent_choice_protocol.json)
5. `bash code/finish.sh` 等待分组齐全后，调用 `code/analyze.py` 计算两视图各自的原始正负余弦分差、不同候选数下的可达性、实际固定槽配对、共享和独立先验干预、单侧准确率及双侧正确数。两视图分差再相减所得的朝向判断用按源图整组的精确符号翻转参考校准；两种措辞留在同一图内。配对区间也按图重采样。执行 `python code/verify.py <上一阶段目录> <UCM Arrow目录>` 会从张量独立算出方向分差，核验逐图像素、归属、全部对照与旧图库重放。
6. 从本次 Git 归档重新执行数值复算，可从 `python code/analyze.py` 开始；调用 `code/verify.py` 还需要上阶段历史部署包与两份 UCM Arrow 文件。保存的原始记录足以重新计算候选覆盖、全部配对表与图库 mR。完整副本通过 `python code/manifest.py --verify` 核对。

补充实验使用同一组已保存的题目与像素。执行 `python code/backbone_choice.py`、`python code/backbone_post.py` 比较历史 LoRA 开启和关闭时的同一直接二选一任务，恢复开启状态的 12 组分数逐值检查。主结果出来后另加同状态对照，`bash code/matched_queue.sh` 重取每次回答字母前的最后隐藏状态，分别送给原语言输出头与 CUP。直接输出头重建的全词表 logits 逐项等于原模型前向结果。运行 `python code/order_checks.py` 可核对交换选项前后的单次实际首选字母、两种顺序都答对的题数。运行 `python code/figure.py`、`python code/example.py <UCM Arrow目录>` 可从归档数据重新制图。

单朝向比较与严格双视图判定都要求正确分差大于零，恰好为零时记未判对。用原图与半转图分差之差作两视图方向判断时，恰好为零记半分。原始逐项分差均保留。本机 CPU 和 A100 服务器各自从原始产物复算，覆盖表、配对表、图库和同状态诊断等 20 个输出逐字节相同。[复算校验](results/local_recompute.json)
