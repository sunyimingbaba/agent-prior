# 同预算 RFPO 复现说明

## 实验入口

计算节点使用私有挂载 `/private/AGSE_E3_1_rebuild_20261112/multicap_rfpo_20261124`，硬件和软件版本由 `records/runtime.json` 实测。GPU 环境运行 Qwen Agent，冻结 CUP、独立评分代理和训练图库在 CPU 环境以 FP32 加载，文本与图像最终相似度按双精度计算。原训练入口的候选采样、top-k 词元支持、重复惩罚、终止隐藏态和对数概率重放来自同一 Git 历史的「E3-2_UCM回填后回答训练_20261124」。原始工具返回、图库与权重摘要在环境清单或相邻报告可查。

训练入口为 `code/prefixes.py`、`code/train_queue.sh`。两个种子分别使用前期 R0 的真实首轮输出锁定训练上下文。每个训练臂独立进程加载相同种子的 R0，运行同一固定图序，保存最终 LoRA 及每步的 16 条采样序列、训练奖励的原始分量、两种反事实排序和一次自由贪心参照。权重保存在服务器的 `pilot/<种子>_<奖励>/adapter` 及本机 `/Users/botlv/cup-deploy-assets/e3-multicap-rfpo-20261124`。训练异常中断时，尚未写入 `complete.json` 的臂从原 R0 重跑。已有完整输出按权重校验。

## 评价与数据身份

`code/photo_pool.py` 从原始 UCM 验证、测试 Arrow 数据生成目视审查图。`code/panel.py` 固化所选图片、三种真／假描述、同场景配对、划分、图片与协议摘要。历史筛选输入快照在 `inputs/screening_snapshot.json`，几何去重统计与数据文件摘要在 `inputs/panel_lock.json`。训练使用此前两批共有 168 张的训练池。新标注 126 张图取自原生验证和测试划分，普通测试指标使用完整 210 张图。普通既有评估成绩已知，新细节图对与措辞在新权重出分前锁定。

`code/eval_queue.sh` 每次载入一份权重，对每个指定面板逐图自由贪心。普通图库输入每图首句，细节面板输入场景提示。一个提示产生一份终止隐藏态。实际工具调用次数另有逐图记录。`code/read_queue.sh` 使用冻结检索器生成图像向量并按权重归档所有原始先验。`code/replay_queue.sh` 用两个 R0 起点重新生成各自第一个 16 候选训练组并独立读出。`code/probe_queue.sh` 读取事前锁定的同图反向偏好对，对两条训练臂的第一个分歧词元计分。所有队列运行状态均可用归档日志复查。

## 本地重算

在本报告目录使用 Python、PyTorch、NumPy 和 SciPy。保持相邻报告目录及其原名称。先核查原始名次完全相同的候选组。正式入口 `orders.py` 用有理数处理并列、平坦奖励显式归零。初次浮点实现的排查材料在 `numeric_legacy`，具体触发步骤见《数值修正记录》。原始归档可重算实验读出与不确定性，主结果无须重新使用显卡。

```bash
export OPENBLAS_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python3 code/check_reward.py
python3 code/audit_train.py /Users/botlv/cup-deploy-assets/e3-multicap-rfpo-20261124
python3 code/outcome.py
python3 code/verify_archives.py
python3 code/probe_pairs.py
python3 code/probe_summary.py
shasum -a 256 -c records/run_logs.sha256
```

`results/per_image.csv` 保存每个面板、图、种子、训练臂的结果。普通召回在并列分数下按可能名次计算期望，先按图聚合五条描述，再计算图搜文、文搜图六项召回均值。细节比较对三个独立措辞等权，严格大于计对。两份种子在同图内配对，每次按源图或整对细节图重采样，区间采用 20,000 次重采样的 2.5% 和 97.5% 分位数。场景层重采样及训练覆盖分层作为补充分析。
