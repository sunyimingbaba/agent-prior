# 第二轮输入的训练图诊断

首个种子的两条训练臂已经完成，部分训练组的 16 条回答词元完全相同。另做一次训练图小对照，检查工具结果的消息角色是否影响可供 R3 选择的先验。该对照在四臂主评价开始前另行登记，所有主实验权重、数据与口径沿用原锁定版本。

从共用训练名单取 12 个自然图对，按固定盐和图对 ID 的 SHA-256 由小到大排序，两侧全部纳入，共 24 张。仅加载未经训练的种子 a R0。每张图保留它在原协议下真实生成的首轮调用、该图的真实工具返回、相同的图像和场景提示。追加文字组重现原输入。分角色消息组将逐字相同的调用放入 assistant 消息，将结果放入 user 消息，再按原处理器聊天模板开始新一轮 assistant 回答。保持首轮调用的原有文字与闭合情况。若模型再次请求工具，各自沿用本组消息格式完成第三轮。原版贪心先验和词元逐图与此前保存的同一 R0 对齐。两种输入各做一次贪心并在相同的两个随机种子下采样两批八个回答。

报告每图 16 个候选中出现几个不同的回答、含有完整且非空 answer 标签的数量、代理奖励有区分的图数，以及确实产生比该图原始贪心先验在留出细节 B/C 与普通描述倒数名次两方面都更好的候选的图数。同时比较两种输入各自只生成一次时的留出两项、各自内部 R3 与 R2 所选候选的留出两项，并报告按图对的区间。该检查使用训练图，目的是决定是否值得在主流程中验证工具回填方式。
