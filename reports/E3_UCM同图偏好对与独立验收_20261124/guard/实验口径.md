# 用普通检索名次约束困难负样本奖励的候选排序

该项评价考察 Agent 为同一图采出的多份先验中，奖励会挑中哪一份。训练侧 168 张图的 16 候选诊断后锁定一个改动。按既有 R2 的真首句及哈希分配的普通负描述，计算首句名次。名次按第 1、2 至 5、6 至 10、11 及以后分档，先按档排序，同档按原 R3 的“普通分差加 κ 倍 A 细节分差”排序。全组沿用相同代理分的秩映射及并列规则。R2、原 R3、带名次约束的 R3 共用全部候选。无工具调用的图保留其唯一先验，按相同图权重统计。

在上阶段 122 张图上首次为此次问题另外采样两个独立批次，每批八条、两份原始 R2 权重。该面板作为新候选复核，其先前单次生成结果已知。依次比较三项：三种留出措辞 C/D/E 的平均正确率，另一半普通负描述及非首句正描述上的 MRR，和按图对配对的 95% 区间。C/D/E 和普通留出描述的得分仅在评价时使用。独立模型复核的 74 对图另行封存。
