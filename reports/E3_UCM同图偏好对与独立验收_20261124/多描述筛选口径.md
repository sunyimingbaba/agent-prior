# 多条普通描述能否改善候选筛选

首句名次分档在新的 122 图候选上保留了细节增益，但普通留出描述的平均倒数排名仍低于 R2。以下轮次用于开发，168 图与 122 图在报告中均标明已使用过。

按原生文本 token 去重。若同图除首句外至少有两种不同描述，按文本 token 哈希固定取一条作为奖励侧补充，余下的替代描述全部留给评价。仅有一种替代描述时，整条留给评价。普通负描述仍按原有哈希分两半。所有奖励方法使用相同的留出正描述、负描述和同一批候选。

在奖励侧，分别计算首句及可用补充描述的倒数排名，取均值。将原 R2 最高分候选的平均奖励侧倒数排名作为该图的下界。先排达到下界的候选，再排其余；同档内按原连续 R3 的普通分差加 κ 倍 A 细节分差排序。沿用旧代理分的同分映射，并统计最终赢家中低于下界的比例。与原 R2、原连续 R3 对比留出细节和普通描述。此试验不改变当前模型入围规则。
