# 对一次生成结果直接计算连续检索奖励

历史候选审计显示，部分第二轮动作在解码后为空或包含 addCriterion。冻结检索器对先验的偏好可以与回答是否具备完整格式分开。在观察本轮开发结果前，登记与离线偏好训练并列的连续奖励试验。它检验检索奖励能否直接改善 Agent 最终交付的连续向量。该分支沿真实自由生成轨迹反传最后一层隐藏态，属于可微辅助目标，与离散动作偏好训练分开报告。

使用同一训练池的 84 个天然正反图对，两张图具有相同场景提示、相反细节。每次两图一起贡献梯度。对每图再用原始首句生成一个先验，用于普通检索保持。当前策略在两个输入下都由原工具循环自由贪心解码，再重放实际终止位置取梯度。冻结 CUP、所有文本向量和主干，更新原 Agent 的 LoRA。对照臂仅用真实首句相对原生困难负描述的平滑排名损失；联合臂在同样的普通检索损失上，加入场景提示下 A、B 真实细节与错误细节的平滑成对损失。softplus 斜率尺度取 50，困难项相对权重沿用前次固定的 κ。两个种子各按固定哈希顺序访问 84 个图对一次，AdamW 学习率 1e−6，梯度范数上限 1。两臂使用相同种子、图对顺序、原生负例、工具和更新次数。最终检查点用于开发排名。硬样本项的梯度由冻结的下游图像编码器计算，记录进入 LoRA 梯度前的数值、重放与生成先验的余弦和实际更新强度。

如实记录单票正确与原生分差，含重复原始描述的负例按文本 token 与既有训练规则排除。新图只调用原 Agent 和原 CUP 的单次推理。
