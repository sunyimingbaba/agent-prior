# E3 多条配文投票在新图上的检索复核

**保留现有 R2 权重和原多描述 R3 作为候选选择对照。** 在 148 张此前未参与配文规则比较的 UCM 训练图上，新采样 4,736 个候选位。147 张有足够多的不同配文可参与主比较。在 16 个候选里确有一个能同时提高普通排名与细节判断时，原 R3 有 50.00% 的概率选中它，投票 R3 为 48.48%。之前在 122 图上看到的细节增益，在这次复核中方向相同，双项选中的收益没有复现。本阶段策略训练为零步。[预先确定的比较方式](实验口径.md) · [主结果](results/summary.json)

## 一张停车场图上发生了什么

图 `1504.tif` 的停车场有许多空位。这次暂时留出普通描述“许多汽车在停车场里成排停放”，用其余同图描述给候选打分。原 R2 只生成一次时，检索器对三种空车位说法答对 0 种，普通描述排第 11。种子 a 的同一批 16 个候选中，原 R3 选出的先验让它答对 1 种，并把普通描述提到第 10。改用投票后，选出的先验让它答对 2 种，但普通描述回到第 11。在这次比较中，细节得分最高的选择和两项都提高的选择分开了。换一条留出描述，同图上投票也有选中双项更优候选的情况。[图像标签及原配文](inputs/panel.json) · [改变双项结果的逐次记录](results/opportunities.json)

## 固定候选之后，哪种奖励更会选

原多描述 R3 参考两条普通配文给候选设优先组，之后按普通分差和困难细节分差排序。投票版只修改优先组。当多数可见配文都认为某候选好于 R2 在该句上的参照，就让它优先，反之移出。两种方法使用完全相同的候选、负图库、细节打分和并列规则。每条非首句轮流留出用于评价，三种细节说法 C/D/E 均未参与当次奖励打分。双项更优要求两项都严格超过同图同权重的原场景贪心输出。[评分实现与锁定规则](code/evaluate_new.py)

| 147 图主比较 | 原 R3 | 投票 R3 | 投票相对原规则的变化与配对 95% 区间 |
| --- | ---: | ---: | ---: |
| 已有双项更优候选时的选中率（主指标） | 50.00% | 48.48% | −1.52 个百分点 [−5.13, 0.00] |
| 选出的先验对三种细节说法的正确率 | 56.29% | 56.70% | +0.41 个百分点 [−0.09, +1.02] |
| 留出普通描述的平均倒数名次 MRR | 0.35304 | 0.35432 | +0.00128 [−0.00143, +0.00450] |

两份 R2 权重的双项选中率分别降低 1.54、1.51 个百分点（以有双项更优候选的组为分母），细节正确率分别提高 0.28、0.53 个百分点。1,108 次“图片、权重、留出句”组合中，122 次有双项更优候选，涉及 37 张图、31 个图对。两种规则在 15 张图的 28 次组合中选了不同赢家。最终是否选到双项更优候选只改变 4 次，集中在上面的同一张停车场图，1 次变好、3 次变差。这批数据给出的结论是投票尚无稳定的双项收益。0.41 个百分点的细节增幅和 0.00128 的普通 MRR 增幅是各自的整体平均值。[分种子汇总](results/summary.json) · [机会与集中度](results/opportunities.json)

## 漏选发生在哪里

把有机会的组按结果拆开，下表每一列合计 100%。在本次有机会的各组里，两规则的优先组都有成员。

| 在确有双项更优候选时 | 原 R3 | 投票 R3 |
| --- | ---: | ---: |
| 选中双项更优候选 | 50.00% | 48.48% |
| 更优候选全部被挡在优先组外，最终漏选 | 42.64% | 40.86% |
| 更优候选已进入优先组，最终仍漏选 | 7.36% | 10.66% |

投票让部分好候选进入了优先组，也让其他候选加入竞争。最终赢家变化少，双项选中率没有随之提高。若在同一批候选中随机选一个，有机会时选中双项更优候选的概率为 11.28%。[事前诊断定义](诊断口径.md) · [漏选分解](results/summary.json)

按评分时可见配文的意见分组，有相反意见的 501 次组合中，双项选中率 49.77% → 46.99%，细节正确率 51.67% → 52.58%，28 次赢家变化都在这里。其余 607 次两规则选出相同赢家。改按整张图统计，92 张图至少一次出现相反意见，55 张图始终没有相反意见。每张图有多条配文，置信区间按原来的 74 个自然图对重采样 20,000 次，同图的句子和种子一起进入区间。[预定义分组结果](results/summary.json)

## 生成的候选给奖励留下多少选择空间

对留出句逐次检查，1,108 次组合里有 412 次是原场景贪心已经在至少一项取得满分。剩余 696 次两项均有提高空间，实际情况如下。表中为逐次计数，包含同一图在不同权重、不同配文上的重复评价。

| 16 个候选里实际出现的改进 | 次数 |
| --- | ---: |
| 同一候选同时提高两项 | 122 |
| 两项都能提高，但分别出现在不同候选上 | 59 |
| 只有普通描述排名得到提高 | 198 |
| 只有细节正确率得到提高 | 83 |
| 两项均未出现高于原贪心的候选 | 234 |

因此有改进空间的 696 次里，有 432 次整组都没有提高细节正确率的候选。仅调整最后的投票门槛，能够影响的是已有候选之间的选择。这一统计促成了单列的等预算候选来源补充对照。[计数与逐折来源](results/opportunities.json)

## 样本与复算

四批旧图共 372 张。本批 148 张和它们的文件名、解码像素摘要均无交集。这批图在历史上做过单次模型验收，本次是首次用于两种配文规则的候选比较。每图用两个种子各采两批 8 个位置。种子 a、b 分别有 135、132 张图在冻结的首轮实际调用场景工具后继续采样，其余依原设置保留首轮终止向量。图 `453.tif` 的五条原配文去重后仅有两条，无法同时拿出两条打分、一条检验，按事前约定保留原始记录、从主比较移出。仅保留两侧均合格的 73 个图对（146 图）时，主指标仍为 −1.52 个百分点。[数据与环境校验](results/audit.json) · [复现说明](复现.md)

独立计算逐图逐权重对照锁定的旧实现，共核对 294 个图像与权重组合，并复现历史单次参照的 882 项细节判断。用同一新实现重放旧 142 图的 1,102 次组合，三个主读数的旧水平、新水平和配对变化及其区间共核对 27 个数，最大绝对差小于 2 × 10⁻¹⁶。[历史重算](results/reference_check.json)

## 因此补做的等预算比较

保留原 R3，在前两批 108 张开发图上固定候选总数为 16。全用场景提示时，整体选中双项更优先验的概率为 5.43%；其中 8 个改用中性观察问题后为 7.94%，提高 2.51 个百分点，95% 区间 [+0.80, +4.47]。全用中性问题时为 9.22%，普通描述 MRR 的点估计则以混合方案较高。下一次独立验证应把两种带问题的来源和全场景对照放在相同预算下，直接看最终能选中多少双项更优候选，并检验普通检索。当前权重继续保留。[等预算对照及完整区间](等预算候选来源结果.md)
