# 多数意见奖励在另 148 张图上的复算

图片来自相邻「E3_UCM同图偏好对与独立验收_20261124」内 confirm/inputs/panel.json，历史用途为验收不同模型的单次生成。两份原 R2 的单次参照来自同目录的 a_start_blind.pt、b_start_blind.pt。锁定脚本核对两份参照、原配文及图片清单的摘要，与上轮用过的四批按图像名和解码像素分别查重。评分用的 A、B 直接按原属性和图对正反标签还原，与 C 的词序一并核验。标签沿用历史目视标注，独立人工复标情况为 [待确认]。

服务器在学校私有挂载 /private/AGSE_E3_1_rebuild_20261112/vote_confirm_20261125 下运行。collect.sh 调用历史原版 GPU 采样器和冻结 CPU 读出器，按场景提示使用同一个工具和两份 R2。原场景贪心首轮如实保留，每图每个种子第二轮各采两批 8 个位置。若该图贪心首轮已经结束，就按原设置将该终止向量填入各候选位。保存动作、工具返回、候选隐藏向量与 CUP 图像向量。压缩包中两套清单分别核查采样和读出。records/runtime.txt 记录实际环境、挂载情况和关键调用文件摘要，records 下的原始压缩包及来源文件供无 GPU 复算。

在本报告目录运行，保留同一 Git 历史下的相邻报告。Python 使用 PyTorch、NumPy 与 SciPy。

```bash
export PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python3 code/lock.py
python3 code/replay_previous.py
python3 code/evaluate_new.py
python3 code/opportunities.py
python3 code/mixed_sources.py
```

重做原始采样时先将本目录的协议、inputs 和 code 拷至上述私有挂载目录，在同目录并行运行 `bash code/collect.sh gpu` 和 `bash code/collect.sh cpu`，待 sampled.done、scored.done 均出现后取回 records 中的归档及摘要。每批种子由原图行号确定。读取器逐图片检查像素摘要及输入；评估另查两批采样的首轮动作、工具输出、权重摘要和单次参照的对应关系。

主分析在每张图、每份权重内部先平均留出的句子，再聚合两份权重。双项选中率用加权成功数除以同样加权的机会数。每轮抽样以原来的自然图对为整体（20,000 次），从而让两个种子、多条配文以及同一图对两侧始终一起进入区间。配文分歧分组沿用全样本图内权重，再在组内归一化。分数相同的最终候选按采样位置等概率计入。所有留出句的候选编号、优先组、赢家和逐项分数可在 records/folds.jsonl.gz 中定位。

开发图上的等预算补充另依赖此前普通配文复核归档的两批 54 图特征、对应的原始随机采样记录和代理排名。混合两种来源后重新计算所有门槛和排序，原问题单一来源的五项平均值与历史结果逐项核对。
