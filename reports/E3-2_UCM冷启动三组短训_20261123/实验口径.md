# E3-2 UCM 冷启动短训

本轮检验更换奖励后，Agent 能否在新的图像上一次生成有助于检索的连续先验。R0 为 Qwen2.5-VL-7B-Instruct 加一份新建 LoRA。R1、R2 分别加载这份权重，策略各更新至固定的第 24 组。训练使用既有 12 对、24 张 UCM 训练图及其场景提示，顺序相同，每图采 8 条，温度 1，每条最多 64 个新 token。沿用单轮策略训练和真实工具参与的部署流程。基础策略、格式判定、学习率、图序、采样种子、结束位置、梯度处理和验证实现均由两组共用。

R1 使用原图在代理图库中的排名倒数，排名从 1 开始计数。R2 取冻结检索器对该图第一条原始描述的余弦分数，减去训练负描述池中的最高余弦分数。负池沿用上一阶段偶数哈希划分，剔除本图所有正描述所在的 token 组。为控制奖励与格式分的相对量级，对当前图先算出 8 个代理排名倒数，再将这些数由小到大按真实分差重新分给 8 条候选，分差相同取并列位置均值。每条完整 answer 均加原格式分 0.2。日志保留原始分差、代理排名、格式分及最终优势。此处明确记录排序后的数值映射，便于判断它对学习信号的影响。

两组均用预测最后一个有效动作时的状态作为先验。EOS 计入采样动作，随后的补齐 token 排除。策略梯度逐条重算，用采样时的实际有效词表、重复惩罚和温度，记录与实际采样对数概率的偏差。优化器 AdamW，学习率 5e-6，梯度范数裁剪 1，同一组内标准化优势。LoRA 秩 32、alpha 64，训练时采用 eval 模式关闭 dropout，LoRA 参数、梯度和优化器更新使用 FP32；主干 BF16。最终一步固定做验证。

主评估为 UCM 原验证集 210 图、每图 5 句，三组分别用该图第一条描述和图像生成一次贪心先验。沿用原始最多三轮工具回填和每轮 64 token 的部署实现，再接同一冻结检索器。主指标为双向 R@1、5、10 的平均，按原图聚合并在固定图库中配对重采样。细节验收沿用 E1 的两个数量措辞各 22 题、属性与空间各 36 题，报告正确数和同一自然图对双侧均对的数量。单种子与训练图覆盖范围限制这轮结论。R3 的额外困难对奖励留给独立的增量对照。

在首轮 R2 的 210 图验证结束前，固定第二次配对重复。仅更换 LoRA 初始化种子（20261123 → 20261124）和组采样种子起点（284000 → 385000），使用相同的 24 张训练图、步数、奖励定义及 210 张验证图。第二次重复也单独加载并验证 R0。两次结果分别报告；联合区间先在同一验证图上取两次增量的均值，再重采样原图，描述在两个已跑种子下的图间不确定性。困难题按数量源图或属性、空间自然图对重采样。

## 补充诊断

主评估之外，用同批验证图的其他原始描述重算召回。按 CLIP token 序列筛掉各图与生成输入相同的句子，图检文同时移除与查询图首句同词元的候选。保留每个有效文查图查询，以原图为单位配对重采样。

首轮主评估完成后，增加训练信号诊断。保持原来的 24 张训练图和场景查询，每图从每个已冻结策略重新采 8 条，使用与策略训练不同的 721000 起始种子。比较 8 个真实图文分差的平均值，另存最优值与候选多样性。按原来的 12 对训练图重采样。这项分析用于判断策略对训练目标的响应，主结论沿用 210 张验证图每图单次生成的结果。

## 运行与核对

基础运行环境、原始模型、评分器和输入指纹见 `records/provenance.json`。首个种子的顺序为 `initialize.py`、分别执行 `train.py R1` 和 `train.py R2`、为 R0/R1/R2 分别执行 `evaluate.py`，再执行 `analyze.py`、`diagnose.py`、`check_end.py` 和 `learning_check.py`。各脚本使用其所在 code 目录的上级作为输出根目录，部署前需建立根目录下的 scratch 缓存目录。`prepare_repeat.py` 接收一个新目录路径，生成第二个种子的运行副本与代码指纹。两次重复都用固定末步权重。

`records` 和 `repeat/records` 保存各自的初始化、训练轨迹及逐图验证指纹。`results` 和 `repeat/results` 保存逐项结果。`verify_local.py` 对本地原始归档逐文件验哈希，再用前一阶段的独立实现复算六项召回。`combine.py` 从两批逐图结果重建联合配对区间。

在两次短训完成后，用 `round_alignment.py` 对固定候选逐轮核对。在初始化 R0、相同 24 张训练图及场景提示上，恢复新采样诊断中相同的首轮 8 条动作，再执行真实场景工具并按部署设置贪心续写至结束。首轮分差逐项核对，随后在同一图片与文本池中比较末轮分差。只在前后均严格分出高低的候选对中统计反转，每图最高分集合保留并列项。以自然图对为单位重采样估计两种选法的平均分差提升。
