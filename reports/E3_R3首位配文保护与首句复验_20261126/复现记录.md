# 样本、采样和读数的复核

本轮工作目录为服务器私有挂载 /private 下的 AGSE_E3_1_rebuild_20261112/r3_first_guard_20261126。使用学校 GeForce RTX 5090，两份 R2 权重分别沿用历史部署的种子 a 和 b。原始首句、同图全部已知配文、每图像素摘要、真实场景工具反馈和随机种子见[采样清单](inputs/real_roster.json)。原有图集、配文库及固定的 R3 评分参数见[输入摘要](inputs/real_lock.json)。98 张图的首句在本阶段重新采样，其场景输入在其他实验中用过。所有图片来自 UCM 训练划分。

每图每种子采两组八个候选，随机种子和输入在写入原始轨迹时保留；另存同一输入的一条贪心输出。两份历史 R2 权重仅用于生成，读出复用原来的冻结 CPU 检索器。评分程序逐项比对每张图的原始首句、工具反馈、像素、两组随机种子、模型权重摘要，以及原始文件到冻结向量的关联。旧面板的普通首选和上轮 R3 逐项重现原报告。所有保护规则在可见配文和奇数负库上作选择。D/E 措辞及留出配文的偶数负库读数用于评价。并列第一等权、两份权重等权，统计区间以自然图对重采样。

归档的两份压缩文件分别保存该种子的原始轨迹、投影向量以及服务器生成的逐文件摘要。每份压缩文件在本机解压核验二进制摘要。[归档索引](archives/index.json)

在包含历史报告资产的仓库内，从本报告目录可用以下命令复算。首次从 GitHub 获取本报告时，先将 `archives/a.tar.gz`、`archives/b.tar.gz` 分别解包到 `records/real/a`、`records/real/b`。每张图的原始记录和评分向量分别位于 raw 和 features。历史开发折和两份模型的参数来自上一阶段已锁定文件。

```sh
python3 -B code/guard.py first78 scene148 scene122 pool first98
python3 -B code/rank_priority.py dev history fresh
python3 -B code/audit.py
python3 -B code/decision.py
python3 -B code/cases.py
```
