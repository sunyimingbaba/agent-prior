# 从视觉核查到新图的单次检索

采用原 RFPO 单次训练对照。先将已在独立自然候选上获得留出细节收益的规则接回策略更新。每步先算完全相同的 R2 分数。原 R2 并列第一的候选等权。较低分回答须在 A/B 两题多答对（严格高于并列第一均值）、在两题较小分差上高于每个首选，且每一条可见非首句真配文的倒数排名都不低于首选均值，才参与改选。在原首选及获准回答之间，按较小分差重新分配它们原来的 R2 分，同一分差均分对应名次的原分。其余候选沿用 R2。该组为严格配文保护基线。

附加视觉方案只检验增量。用相同冻结 R0 单独看图选 C 措辞的两条相反描述，交换显示顺序。两个顺序都严格选中本图标注的真句，才使用这项视觉依据。当严格配文保护基线已改变任一候选的 R2 分值，完全沿用该基线。其余组中，若原 R2 分较低的候选，其 A/B 正确数及较弱分差分别不低于首选均值，并且该候选在 C 真句对假句的原生检索分差为正、高于全部原首选的 C 分差，且通过完全相同的逐句配文保护，则以 C 分差在获准集合和原首选之间重排原分。原生 C 分差按该图带候选隐藏态的融合图像向量和冻结的 C 正误文本计算。因此同图不同候选可以有不同的分数。对照包括同一附加规则跳过看图判断直接用 C，以衡量看图这一步的独立贡献。

评估先在既有 194 图的两批实际回填候选和不同的 116 张新图的一批候选上轮流藏起一条配文。C 不参加 D/E、F/G 措辞验收。每图平均各留句和适用的种子，按自然图对重抽 20,000 次，固定随机数 271127。两图库此前有使用记录，均按像素与本次 RFPO 训练图区分。预先要求在 116 图上视觉附加相对严格基线的 D/E 或隐藏配文 MRR 有一项配对 95% 区间下界大于零，另一项点差非负；194 图这两项点差均非负。还须相对跳过看图的 C 对照在 116 图至少一项点差为正，才会触发额外的视觉臂训练。本轮直接检验已过独立候选复核的严格基线。

使用原筛图训练的 24 图、相同起点、图序、采样随机数、优化器及更新预算。八个第二轮回答随当前策略更新；首个图组无权重分化，可与原 R2 逐项核对。通过原来的冻结检索器，在 UCM 210 图生成一次先验并评估，106 图比较细节与其他配文，另在 56 图换第二套细节说法。主验收沿用 D/E 的配对差下界高于零、另外两项不下降。冷启动直接看图分数、训练候选表现和末步模型单次检索分别列报。若视觉臂晋级，另与同时期严格基线对照。
