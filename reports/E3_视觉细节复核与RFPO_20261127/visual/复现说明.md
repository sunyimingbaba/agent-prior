# C 两种说法的看图判断与候选回答检索分差

共 336 张像素互异的图。训练 24 张，主验证 194 张，独立图库 118 张。逐图输入、真句和假句、正反两侧的固定展示顺序、像素校验值见 `inputs/rows.json`。原数据表中 `C[0]` 是该图的真句，`C[1]` 是假句。`side` 是该图的标注侧，取 0 或 1。`options_side0` 中第一句对应侧 0，第二句对应侧 1。每图按其原所属图库读取 C 的具体措辞，保留原表述与冻结文本特征。

## 冻结模型直接看图

在 5090 的已有 E3 环境中运行 `code/visual.py`。模型读图后比较 C 两句，保留下一词为 A、B 的两个原始 logit。第一次将侧 0 放在 A，取 A 减 B。第二次将侧 0 放在 B，取 B 减 A。两个顺序使用相同的提问模板。

每图的两个校正分为 `results/teacher.json` 的 `order_margins_side0`，正数支持侧 0。`margin_side0` 是它们的均值，`margin_true` 是朝该图标注真侧的均值。`verified_truth` 表示两个顺序各自严格支持标注真侧，任何一次平局都记为假。通过此项核实的训练、主验证、独立图库图数依次是 15/24、96/194、67/118。原始 A/B logits、两次完整提示和输入词元校验值保存在 `results/visual/`。

## 每个回答在 C 上的原生检索分差

`inputs/c_vectors.pt` 以文件名为键，每张图的张量为 2 × 768。两行依次是真句、假句的冻结原生文本向量。对同图每个回答，用其 3584 维隐藏状态和原图得到融合后的 768 维图像向量。文本向量各与图像向量做一次内积，再取真句得分减假句得分。

训练和主验证的种子 a、b 各有 218 个有效图组。使用上一阶段原始隐藏状态文件，以原 4 线程 CPU 逐槽前向计算图像向量，回验归档的 A/B、D/E 以及有标注时的 F/G 分差。独立图库种子 d 逐图核对原先已归档的融合图像向量和源文件校验值，在 116 张实际产生八个回答的图上按同一算法计算。其余两张的可用性记录也随档保存。每个图组八个位置及重复回答的顺序与原采样文件一致。`results/candidate_margins.json` 以种子、文件名为两级键，每组为八个真减假分差。`results/complete.json` 给出逐种子回验最大误差及汇总文件的 SHA-256。

## 复算与存档

服务器工作目录为 `/private/AGSE_E3_1_rebuild_20261112/visual_detail_rfpo_20261127/visual`。视觉问答使用 `/private/AGSE_E1_20261110/e1_prior_compat_20261111/venv/bin/python`，原生检索器按 `code/read.sh` 使用 `/private/AGSE_E1_20261110/legacy/env/bin/python`。在保留原有相对目录结构的副本运行下列步骤。

1. 本地 `python3 code/prepare.py` 从三个图库的原表和原文本库建立逐图输入和文本向量。固定源文件的校验值见 `inputs/lock.json`。
2. 服务器运行 `code/visual.py` 和 `bash code/read.sh`，将 `results/visual/`、`results/candidates/{a,b}/` 及视觉完成清单同步至本地。
3. 本地依次运行 `python3 code/pack.py external`、`python3 code/pack.py teacher`、`python3 code/pack.py all` 和 `python3 code/archive.py`。独立图库的原生视觉特征和逐槽回验读自上一阶段 `followup_pool/readouts/` 及 `scores/`。
4. `archive/visual.tar.gz` 保存 336 份两顺序原始记录，`archive/candidates.tar.gz` 保存 a、b、d 共 554 份逐图记录。`archive/SHA256.json` 列出两个压缩包及包内所有文件的校验值。将两包解压至 `results/` 即可还原逐图校核材料。
